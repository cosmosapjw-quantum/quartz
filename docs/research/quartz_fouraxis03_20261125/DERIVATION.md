# Exact knowledge and statistical search
For state s, exact value V(s)=max_a -V(T(s,a)) and terminal V=outcome. Store I(s)=[L,U] subset [-1,1] with integer WDL endpoints. For unexpanded/unknown state I=[-1,1]; all legal actions included even if not native-materialized. For registered complete child list, action I_a=[-U(child),-L(child)], parent F(I)=[max_a L_a,max_a U_a]. Monotone under information order (interval inclusion); terminal exact. Induction on legal depth establishes soundness for any finite set of registered transitions. Refinement of one node can only narrow all ancestors; worklist reverse incoming arcs propagates every change, including transposed parents not in sampled path. No cycles because each legal transition increases ply; integer endpoints imply each bound moves at most twice, termination O(E) incremental notifications up to degree factors (recompute max over actions). If all reachable nodes registered, backwards induction recovers exact minimax; finite search need not register all. Exact board plus side key: two bits each of 42 cells and side bit84, injective for valid unrestricted Connect4; terminal status derivable from legal board, no root gate/repetition rules in scope.
For a candidate a, safe strict elimination if U_a < max_b L_b; at least one candidate survives. If root L=U, some action lower endpoint equals U; any such action is certified optimal, including unmaterialized legal action. More generally robust certificate if L_a>=max_{b != a} U_b, including equality; for a single action trivial. Worst-case WDL utility regret of choosing a is bounded by R_a=max(0,max_{b!=a}U_b-L_a)/2 (empty competitor max=-1). R*=min_a R_a; R_a nonincreasing as all intervals shrink. Zero regret certificate can exist even if value interval does not collapse (single legal action, or overlapping bounds meeting at a boundary). STOP on certified optimum, not on Q variance: choose certified action even if not visited; lower-bound value may remain uncertain. This is risk bound, not expected utility. A myopic certificate-information value g_cert(c)=R*(H)-E[R*(H')|H,c]>=0 for sound refinements, bounded <=R*(H); net g_cert-lambda cost. If action rule uses approximate Q rather than minimax-regret selection, actual signed WDL gain can be negative; do not conflate. Original Gibbs prior over feasible phase actions can mix signed-gain and certificate value only with explicit utility/risk weighting.

If no eligible visible edge, increase prefix width to first eligible candidate, blocking materialization to avoid parallel best-effort zero eligible case. At solved internal node stop descent, use exact value on that sample, do not infer exact ancestor value from Q. At solved root (for no-STOP control) choose optimal witness on each descent so path always nonempty. Root output keeps native recommendation if non-dominated unless certified optimal action exists; else prefer most-visited admissible action with stable tie. Root STOP at completed block boundary if any action certified optimal.
