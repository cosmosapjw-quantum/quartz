# Reversible geometry and conditional cost allocation
For a length-k window w let c_i(w) count stones of player i, e(w) its empty set. For player i, a live immediate window has c_i=k-1,c_other=0, and a pair window has c_i=k-2,c_other=0. Define I_i(x) as number of live immediate windows with unique empty x; P_i(x,y) as number of live pair windows with empties x,y. Completion set is I_i(x)>0; adjacency is P_i(x,y)>0. Multiplicities, not boolean updates, are necessary: two overlapping windows may support one completion or pair. Keep integer counts (max incident windows<=4k), bitsets for positive support, and support totals M_i (# immediate+pair windows). Track S_i(x) = number of such windows incident to empty x. On placement m by j, only windows containing m change; remove each old contribution, update c_j and empty cell, add its new contribution; undo exactly reverses operations. Invariant by induction on make/unmake. Each update touches at most 4k windows, versus all N=88/572, excluding fixed root initialization and constant per-window bookkeeping. Reversible update visits counted, not equated to CPU. Exact terminal window counts. Forcing proof uses same K43 candidate order and root cap/query checks, same immediate counterwin priority. Mode I identical observations and budget path by inductive state equivalence, independent of implementation cost. This is a behavior preservation claim, not all minimax.
Necessary filter: for opponent i and mover j!=i, c_i(w) fixed, live immediate/pair window survives iff m not in w; no newly qualifying window can be created. Therefore M_i' = M_i-S_i(m). If zero, no opponent completion or pair candidate; the restricted attack routine cannot establish a win (including depths1/2, where condition is conservative). Skipping such calls leaves root interval unchanged, never converts UNKNOWN to FALSE. At fixed uncapped restricted traversal, skipped calls contributed no proof, same bounds/cert. Under finite global cap F may consume fewer queries and discover additional facts, so compare I vs F without assuming identical capped outcomes. More facts need not preserve exact tie choice or full-game utility. Root certificate O(E) via largest upper bound and multiplicity, exclude candidate's own upper bound; for equal values preserve original ordering.
Cost allocation: let Z encode own and opponent pair-support presence before proof. Given measured locked cost C_L, proof-only C_d and independent root-feature extraction C_Z, proxy H_d=1_cert(d) C_L-C_d-C_Z, H_0=-C_Z. For deterministic bin policy maximize empirical sum H over d in {0,3,5,7}; no-proof selected if no positive incremental contribution vs feature-only. All policy options pay feature cost; unconditional L pays none. Objective is resource saving conditional on fixed selected locked action if no proof, not regret utility or exploitation; exact certificate and weak losing-action replacement separate. Nonadaptive matched-budget mixture: with measured aggregate cost of policy, choose convex combination of fixed policies bracketing same cost; compare certificate/changed rates and NN at matched expected CPU, not head-to-head games. Need prospective CAL and TEST on fresh opening families; actual cost per move can differ through trajectory changes.
