# R6. Independent adversarial conditions, failure construction and minimal repairs

Soundness check: R5 Lemma1 requires the **opponent has no immediate winning action before a**, not merely that the current player has no win. Counterexample: t has a horizontal three and can make an open four with action a, but o already has an unblocked four elsewhere; o can win at b before t uses the two endpoints. Therefore code must explicitly check both original potential-win sets, not assume all legal source histories are threat-free.

Locality check: no assumption that a is in the neighborhood of the **last** move. All 225 legal candidate moves must be scanned (or an exact completeness-preserving filtering), each to up to32 possible c. A naive "near recent12 history" mask could discard the certified fork. Negative boundary test: a at row edge and c at boundary; reject c outside [0,14]^2 before indexing. Counterfactual W_o(s) must use o-colored hypothetical wins, not Rust current_player's own legal-move state. D4 reflection/rotation must preserve fork membership and map the witness endpoints consistently.

Tactical counterexample: 2 distinct windows may yield the **same empty winning cell**. Count *distinct cell indices*, not two different line segments. A completed five at a is a terminal move and outside the new claim even if it carries multiple winning windows. Existing win in one for either player invalidates nonterminal witness testing. A white move that blocks one endpoint but creates a separate white immediate win *at that move* would contradict the no-W_o(s+a) precondition; check original potential wins correctly.

Causal framing critique: comparing learned_fork_mask with learned_full confounds certificate scan overhead and root gating. Add a matched-computation full-legal witness control if feasible; otherwise label observed contrast "complete controller pipeline" and never pure mask causality. Similarly proof-choice override directly follows a proof and must not be called a pure MCTS sample improvement. If no omitted fork in heldout, conditional effect not estimable, not null superiority. If positive controls are accepted by construction, probability statements are conditional on selection and do not generalize to normal game distribution.

Statistical check: game moves within a game are dependent; paired color swaps on a shared opening are ONE block, not 2n independent roots. Small WDL counts warrant interval/blocked claim rather than Elo. Same prior-v0 evaluator could be tactically inferior to reference engines; do not claim it models human Einstellung. Real wall-CPU excludes external serialization and disk-load consistently for arms; verify actual per-stratum mismatch. C16 full games should be generated without preloading a label into the online policy.

Independent level: adversarial analysis here is parent-model fresh pass with different counterexamples; not falsely labeled a separate subagent. Closure: conditional theorem is sound subject to direct bitboard and game-rule audit; no strong no-go or broad scientific impossibility admitted.
