# Finite-horizon decision certificate and transport
Let N_a(t) be root edge visits after t committed backups, sum N=t, one nonnegative unit per backup. Fixed priority smaller action index wins ties. Let L=argmax (N_a,-a). For rival i, minimum number of future rival-only backups to displace L is d_i=N_L-N_i+1_{i>L}. Thus d=min_i d_i; no rival => infinity. Remaining allowance r=H-t. For any nonnegative integer increments x_a with sum<=r, (N_L+x_L)-(N_i+x_i)>=N_L-N_i-r. If d>r then L wins every possible completion, including equality handled by priority. Conversely if d<=r, allocating d to an eligible rival displaces L in the unconstrained vote simplex (not necessarily reachable under PUCT). The certificate is sharp for that relaxation, sufficient for actual PUCT. At t=H, d>=1, so ordinary recommendation equals lock result. Under deterministic identical evaluator, selector, legal set, shared gate and cold-start, L_H and B_H choose identical moves: induction on each game ply yields equal histories, same outcome. No assumption that visit winner is optimal, or that lock at H=20 preserves H=32. An actual value-of-computation claim is conditional: the marginal effect of continuation on terminal decision utility of the *same finite-horizon recommender* is exactly zero at lock, but not general EVSI/minimax.
Shared gate G(s) returns an exact action or unresolved. For any fixed common root distribution with P(G unresolved)=p, both gate branches choose identical move and spend zero NN rows; E[C_B-C_L]=p E[C_B-C_L|unresolved], E[C_B]=p E[C_B|unresolved]. Therefore NN relative savings is conditional savings (p>0), not diluted by gate frequency, but absolute savings is diluted. If gate cost g(s)>0 is charged to both, total relative saving = p E[C_B-C_L|unresolved]/(E[g]+p E[C_B|unresolved]) for same additive units. This identity applies to same-state comparison only; differing policy trajectories change occupancy and prevent naive causal decomposition. At root utility u in [-1,1], |E[u(A)-u(B)]|<=2 P(A!=B) under common reference; sign unresolved when actions differ.
