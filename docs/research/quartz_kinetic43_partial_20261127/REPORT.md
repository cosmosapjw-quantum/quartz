## K44 constructive direction
Main result: partial proof now activates in early-start play and materially improves weak small-NN decisions. Rapfi resource bottleneck: loss sweep re-scans 572 windows for many quiet opponent successors; most extra proof does not replace expensive locked NN search. Need a cheap necessary-condition prefilter, not learned posthoc depth tuning. At fixed board, an opponent completion window or two-empty unblocked window can only disappear (never be created) by a move of the other color: all line counts of opponent fixed and opponent-unblocked windows may be blocked. Therefore if after root placement no surviving opponent immediate or two-empty threat window exists, restricted forcing search cannot start (UNKNOWN, not disproof). Precompute opponent immediate/pair window supports before root moves and update affected windows via per-cell incidence. Skip provably fruitless restricted search attempts, maintain exact receipts and compare old/new on all K43 source states at same depth and budget: fewer consumed queries may increase proof coverage, so no blanket identical-result claim under budget; with untruncated finite restricted tree, same reachable proof set.
