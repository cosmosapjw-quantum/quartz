# C5. Actual policy-only learner and native 15×15 MCTS path

Implemented source: coding/policy15.py is 13-component board-only legal-action feature extraction, differentiable convex supervised finite-teacher log-linear model with full-batch damped Newton, L2 lambda .01 and readback metrics. This is NOT an externally provided pretrained NNUE and has no trained value head. Rust src/mcts_server/prior15_cpu_server.rs uses the identical feature map and a strict model JSON schema and stores trained prior as real Evaluator<Gomoku15> for EVERY new MCTS node, not just a root ranking. src/games/gomoku15.rs grants a read-only board getter (no rule mutation). src/mcts_server.rs registers separate trained-vs-uniform fair-CPU research endpoints and feature inspection.

Rust execution: parser rejects teacher/oracle fields, invalid Freestyle history and non-finite model coefficients; whole legal root slab always preallocated; source prior covers all legal actions; 8-visit first phase and bounded 1-visit continued MCTS share same root pointer/hash and N/W/M2/P; only learned_gated restricts top16 initial candidates, then permits up to four omitted own immediate wins or opponent immediate-win blocks with board-only evidence. learned_all_legal and uniform_all_legal do not restrict candidates. Search target 20,000µs measured after frozen model file load and before initial policy inference; wall time includes internal evaluation, masks, oneply rules, root setup and MCTS; output serialization and model disk loading excluded explicitly. Per-stratum actual cost still must pass an independently checked 10% mean gate.

Validation expectations: existing Rust unit/integration tests plus new tests for 225 legal actions, index224, trained-value-zero, malformed input and teacher leakage; Python gradient and D4 tests; cross-language feature parity after compilation. No scientific result is admitted solely from source code.
