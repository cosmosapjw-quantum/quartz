# Signed decision value with a reusable low-horizon prefix
Let fixed priorities tau(a) define ties, n_a committed visits, each future backup increment exactly one legal root edge. For leader L, define d_i=n_L-n_i+1[tau(i)>tau(L)] when smaller tau is preferred, i.e. add one when the rival loses a tie. d=min_i d_i. If d>H-t then no admissible suffix changes the recommendation. For H2>=H1, certificate at H2 implies certificate at H1 (since H2-t>=H1-t); therefore first exact stop t_H1<=t_H2 along common prefix, and continuing at t_H1 reuses all already paid work. For a coherent quiescent snapshot with r outstanding reserved but uncommitted unit backups, cap H, count t, require t+r<=H. A valid stop certificate d>H-t includes all outstanding and undispatched increments; stop dispatch and drain. A stricter drain-only bound d>r preserves the current leader against pending increments, not against the entire original cap. Asynchronous nondeterministic completion can change future search choices; no claim of paired-path equality without common deterministic prefix.
For fixed root s and model, denote actions a_l,a_h, costs c_l,c_h from L20,L32, delta=U(s,a_h)-U(s,a_l), k=c_h-c_l>=0. Delta=0 when actions coincide, exactly, no label required. For feature Z at low stop, E[delta|Z]=P(flip|Z)E[delta|flip,Z], with undefined conditional gain on zero-probability flip and product interpreted as zero. For U in [0,1], delta in [-1,1], |E[delta|Z]|<=P(flip|Z); flip probability is an upper bound on magnitude, not signed value.
For a deterministic binary extension policy m(Z), incremental priced score relative to low is J(m)=E[m(Z)(delta-lambda*k)]. For finite frame rows, define S_z=sum_{j:Z_j=z}(delta_j-lambda*k_j). Max over all 2^4 tables is separable: choose bit z iff S_z>0, with ties prefer lower incremental cost then smaller mask. Gate roots are structural zero, so exclusion does not change optimizer (but affects absolute mean if mixing frames). Population optimum with known conditional means is sum_z P(z)max(0,E[delta-lambda*k|z]); convex max implies >= max(0,E[delta-lambda*k]); empirical training gains do not establish held-out gains. Relative cost of low vs high cannot be inferred from cap ratio alone: terminal leaves/gate/early lock affect actual c. With shared prefix, no duplicated row cost; feature computation is separately included in measured CPU/wall time. On fixed roots cost telescopes B32-L20=(B32-L32)+(L32-L20) or (B32-B20)+(B20-L20). Game trajectory distributions differ for unequal caps; per-move ratios do not telescope across distinct matchups. The 2x2 allowed game design uses Quartz candidate cap L and plain baseline cap B; exact same-cap path equivalence makes reversed unequal-cap arms complementary on the same deterministic opening pairs; any departure is an implementation/identity finding, not independent strength evidence.
