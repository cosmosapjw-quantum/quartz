# R2. Relevant primary literature and current code

* Allis, van den Herik, Huntjens (1993) *Go-Moku Solved by New Search Techniques*, original AAAI report https://cdn.aaai.org/Symposia/Fall/1993/FS-93-02/FS93-02-001.pdf ; also Computational Intelligence (1996), https://onlinelibrary.wiley.com/doi/10.1111/j.1467-8640.1996.tb00250.x . Distinguishes freestyle overlines, straight-four (two independent next-turn wins), threats and generalized winning threat-space search, proof-number search. Already a solved-game algorithm under its explicit variant: do not claim the tactical certificate itself novel.
* Allis, van der Meulen, van den Herik (1994), *Proof-number search*, Artificial Intelligence 66, pp 91–124, https://doi.org/10.1016/0004-3702(94)90004-3. General proof/disproof search predates current work.
* Chaslot et al. (2008), *Progressive Strategies for Monte-Carlo Tree Search*, https://project.dke.maastrichtuniversity.nl/games/files/articles/pMCTS.pdf. Reopening and progressive unpruning are prior art; C16 novelty candidate, if any, is a measured conditional finite-cost mechanism, not unpruning itself.
* Doe, Winands, Kowalski (2022/2023), *Combining Monte-Carlo Tree Search with Proof-Number Search*, https://ludii.games/publications/COG2022.pdf . Their Gomoku experiments reported PN-MCTS was worse than basic MCTS for several finite-time conditions, illustrating that attaching search proofs has runtime/tradeoff risk.
* Jin, Duan, Hang (2025), *Rapfi: Distilling Efficient Neural Network for the Game of Gomoku*, https://arxiv.org/abs/2503.13178 . Actual Rapfi external NNUE is different from QUARTZ policy-only learned model; prior model fidelity is source-limited.
