# Early state and decision value
Given latent action vector theta, current information I and action a(I), posterior regret R(I,a)=E[max theta-theta_a|I]. After computation O, a'=a(I,O), tower property gives R(I,a)-E[R(I,O,a')|I]=E[theta_a'-theta_a|I]. For fixed I, factor = P(a'!=a|I) E[theta_a'-theta_a|I,a'!=a], with product zero when P=0. If actions are posterior-mean maximizers, E[max E(theta|I,O)|I]>=max E(theta|I) by Jensen, so ideal expected VOC>=0. Arbitrary search decision (visit leader/proof replacement) need not maximize posterior mean; actual effect can be negative. For deterministic fixed opponent and fixed continuation, two actual scores Yc,Y0 differ only if selected action differs at common state. Thus D=Yc-Y0=A*D, A=1[a_c!=a0]. E[D|X,E]=p(X) m(X) where E reached and X predecision. P(E)*conditional mean is unconditional policy effect, don't multiply by P(A) twice. Changed outcome is a subset of changed action; mediator not an admission feature. With unknown true minimax values Yc-Y0 not true regret, no sign guarantee. For binary action change, squared loss decomposes: E[(D-q)^2|X]=Var(D|X)+(E[D|X]-q)^2. Use Beta(1,1) posterior mean for empirical flip probability within predeclared cell, signed mean among changed cases with zero-centered pseudo-count4; product shrinks sparse estimates, not literal conjugate game-value posterior. Compare constant train mean on reached roots; Brier flip and MSE D on held-out CAL/TEST. Nonreach contribution exact0; report overall score/calibration separately.
