# Finite fork causal variance geometry
For fixed root/seed i, a,b in {N,F,X}, y_ab=U(d_ab)-lambda K_ab, fixed protocol with same initial H and identical middle H_a across b. Let e_a>0, f_b(a,H_a)>0 and g_ab=e_a f_b. Fixed policy pi chooses distribution pi1(a|H), pi2(b|H,a,H_a); rho likewise. Define d_ab=pi1 pi2-rho1 rho2, sum d=0. Contrast Delta_i=sum d_ab y_ab. Under sequential randomization independent of fixed potential tree, observing (A,B)~g, path contrast IPS with common prestate anchor m(H): T=d_AB/g_AB (y_AB-m). E_g T=Delta_i exactly. Variance=sum d_ab^2/g_ab (y_ab-m)^2-Delta_i^2. Let w=d^2/g. If w total zero identical policy then T=0 for all paths; otherwise minimizer m*=sum w y/sum w; excess variance=sum w*(m-m*)^2 by completing square. For deterministic distinct policies uniform logging, oracle mean of two terminal rewards, not prefix utility. For online restricted m(H), minimize E[Var_g(T)|H], yields m_H*=E[sum w y|H]/E[sum w|H], not necessarily mean of oracle anchors when w varies with post-first state. For two deterministic policies with uniform g and differing choices, conditional on H, weight is indicator of policy disagreement; regression weighted by that indicator, training only. Common shift y->y+k, m->m+k leaves T invariant and Delta unchanged; wrong anchor increases variance relative oracle, can worsen raw IPS. Exact offline prefix utility is privileged comparison only.
Sequential DR for a fixed policy: q2(H_a,a,b) arbitrary frozen terminal reward estimate, v2=sum pi2 q2; q1(H,a) arbitrary frozen estimate of v2, v1=sum pi1 q1. Let r1=pi1/e, r2=pi2/f. D_pi=v1+r1(v2-q1)+r1*r2(y-q2); y includes both costs once. Conditional E_b last term = r1(sum pi2 y-v2). E_a cancels q1/v1 and returns sum pi1 pi2 y. Subtract D_rho for contrast; exact finite-design unbiasedness (Wager 14.21, Jiang-Li Eq10). Given full fixed fork, conditional variance of contrast exactly Var_a(E_b[D_pi-D_rho|a])+E_a Var_b[D_pi-D_rho|a]. If policies agree first action, first weight identical but future choices may differ, so cannot cancel entire first-level terms unless q1 contrasts also equal. If full policies agree, same nuisance construction yields score zero; if different nuisance functions used, mean zero but not pointwise. For actual deterministic target paths, compare paired exact truth; logging estimates diagnostic only. Full path replay deterministic seed; pseudorandom permutations log first path with known design e=f=1/3. No adaptive normal approximation.
Sequential VOC: V2(H_a)=max_b E[Y_ab|H_a], V1(H)=max_a E[V2(H_a)|H], with fixed resource schedule, or add STOP and per-stage costs when unequal. Value of feedback relative to best fixed sequence >=0 under coherent oracle conditional expectation because static sequences subset of dynamic policies; fitted policy can fail. For deterministic full root simulator, V1 is population decision conditional on chosen observable features, not root oracle. Mixed interaction J_ab=y_ab-y_aN-y_Nb+y_NN (same end readout/cost). J can have either sign; does not claim physical coupling. If sequential targets differ after first intervention, J measures protocol interaction, not pure fixed-edge interaction. Equal NN target vs total actual achieved differs; retain cap misses in primary intention-to-protocol and report matched subset descriptively.
Info: for history H, sequential randomized A independent U conditional H, B independent U conditional H,A,Z1, so I(U;A,Z1,B,Z2|H)=I(U;Z1|H,A)+I(U;Z2|H,A,Z1,B) under logging law (conditional MI averaged over A,B). With compressed state S=f(H,A,Z1), conditional independence may fail under other behavior policies. For adaptive deterministic target choice B=f(history), action adds zero conditional information given complete history, not after lossy compression. This is a chain-rule identity, not Massey's directed information I(X^n->Y^n) unless explicit causal variables agree. K21 Gibbs response increment exact for score vectors with fixed reference; not calibrated latent MI. K22 predictive failure motivates channel mixture L_alpha=(1-alpha)P(Z|H,a)+alpha P(Z|U,H,a). Positive finite support, shared prior; choose alpha using CAL log loss, alpha=0 permitted; do not equate validation score to utility. If marginal base model is induced by same shared prior P(U|H), mixing preserves response marginal and coherence. Conditional log gain heldout may be negative even when model MI positive. Evaluate model MI, EVSI as diagnostic, not policy objective. K22 compression-loss bound remains conditional on true coherent law. No novelty claim.
