# Reservoir opportunity and information decomposition
Let L finite, A nonempty subset of L chosen using F. U_i bounded in [0,1], m_i=E(U_i|F), V_A(F)=max_{i in A}m_i, H(F)=E(max_L U_i|F). Conditional Bayes risk R_A=H-V_A. For actual choice d in A, exact realized regret=max_L U-max_A U + max_A U-U_d. For nested sigma fields F⊂G and F-measurable fixed B⊇A, tower gives H(F)=E[H(G)|F].
Thus R_A(F)-E[R_B(G)|F] = E[V_B(G)|F]-V_A(F)
= (V_B(F)-V_A(F)) + E[V_B(G)-V_B(F)|F]
= E[V_A(G)-V_A(F)|F] + E[V_B(G)-V_A(G)|F].
The first expression separates prior access value and information value in expanded set; the second separates information in original set and incremental access after observation. Jensen ensures both information terms nonnegative; access terms nonnegative pointwise. If B is G-measurable and contains A a.s., only the second decomposition is generally valid; conditional selection before observation is needed for the first. No claim for dropping incumbent, realized gain, uncalibrated scores or non-nested utilities. Difference of two treatments at equal cap can be negative.
With U in [0,1], exact proof bounds l_i<=U_i<=u_i give deterministic regret ceiling max(0,max_{i≠d}u_i-l_d); adding i=d to maximum gives a safe but looser ceiling. If all outside upper bounds <= max_A lower bound, omission identically zero. If only score gaps, no such certificate. For admissible computation c with cost C_c>0, expected net gain ΔV_c-λ E[C_c|F], λ utility/time, or ΔV_c/E[C_c|F] as local ratio; ratio vs net is not identical global Bellman policy. Candidate expansion may be chosen as computation plus recommendation access, not as independent heuristic. Distinguish candidate acquisition from epistemic update. For realized same-snapshot expansion gain ΔU=U_{d_B}-U_{d_A}=omission(A)-omission(B)+ranking(A)-ranking(B). Omission drop nonnegative but ranking may increase. Example U=(1,.5,0), A=(1,2), B=(1,2,3), noisy scores (.1,.2,.3) yields worse decision on expansion though omission unchanged. No iid assumptions.
