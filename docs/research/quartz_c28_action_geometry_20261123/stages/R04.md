# R04 — explicit competing constructions and discrimination

Use independent product r_i=0, common loading (r,r,r), and signed loading (r,r,-r), all with exactly the same m=0 base marginals. Let A have equal mass at0 and1/2; B,C equal mass at0 and1. The incumbent is b=1/2; costs are c for A and d for each target. A is a pure-information query because U_A<=b.

For the signed case define x=1/4-d and t=(1+r^2)/4-d. Direct decomposition gives K_A=-c+[t]_+ and K_B=K_C=x+[t]_+/2. For common loadings define l=(1-r^2)/4-d: K_A=-c+([t]_++[l]_+)/2, K_B=K_C=x+[l]_+/2. STOP has excess0. The total H2 value is b plus the maximum of all four first choices; merely showing A beats STOP would be insufficient.

At r=4/5,c=1/100,d=3/10, the signed first scores are (1/10,1/200,1/200), common scores (9/200,-1/20,-1/20), and product scores(-1/100,-1/20,-1/20). Values are respectively3/5,109/200,1/2. The direct consequences are different paid optimal values under fixed marginals, and information-only selection in both coupled examples at these costs. This is not empirical game efficacy.

The common and signed joint laws are related by the bijection C->1-C. Thus I(A;(B,C)) and I(A;Z) are unchanged, while the selectable numeric payoffs have different alignment. This is a decision-specific counterexample to inferring VOC from a scalar information quantity; it does not contradict Blackwell's theorem or prove a general information-method no-go.
