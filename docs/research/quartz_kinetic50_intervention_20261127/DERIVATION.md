# Finite-opponent computation intervention
Let omega=(opening family, frozen checkpoint, color, preassigned eligible ordinal k). Fix both baseline and subsequent Q20 policy. A0 always stops at L20; A1 extends at kth noncert Q root only, using same tree and proof. Before the event, policies have identical history and decisions by deterministic induction; cert roots do not count. E(omega)=event reached is therefore a pre-intervention variable shared by both arms. Both arms produce terminal scores Y0,Y1 in {0,.5,1}; observe both in actual separate Q-v-B games, not counterfactual imputation. If E=0 or event action same, determinism implies all subsequent actions identical (stateless root searches, same evaluator, identical fixed continuation); DeltaY=0. Therefore tau=E[E DeltaY]=P(E)E[DeltaY|E]. Writing A=indicator action differs yields tau=P(E,A)E[DeltaY|E,A] in this deterministic design; A is a post-intervention mediator, not a valid predecision selector. In stochastic games same event action need not imply identical future outcomes; the equality requires shared deterministic continuation.
Let L=C1_event-C0_event>=0 (cumulative NN calls), D_Q=C1_Q_after-C0_Q_after and D_B likewise. Before event counts equal; Delta C_Q=L+D_Q and Delta C_total=L+D_Q+D_B. These can be negative when trajectories terminate earlier. Wall/CPU may differ even before event due to runtime noise. Define gain/local NN ratio tau/E[L] only for positive E[L]; distinguish net game compute and do not divide by signed near-zero cost. Finite-game utility is U_pi(s,a)=expected terminal score for fixed post-action policies and environment; difference equals regret decrease for that U_pi, not WDL minimax or original Bayesian theta.
