# C02: exact generic computation observer interface

Functions accept only a task-neutral initial posterior + terminal utility + observation channel or conjugate posterior arm sufficient counts. Beta adapter takes array of (alpha,beta), independent arms, samples per arm, computes joint count probabilities, posterior action utilities, and E_y[max]-max(E). Finite sensor adapter takes prior over latent states, normalized L(theta,y), bounded matrix U(theta,a), samples n and counts multinomial, returns same typed EVSI outcome. Both outputs include G, before utility, after averaged utility, mass error, count support, and exact evaluator elapsed microseconds. Unknown hidden state labels and actual future choice MUST NOT be inputs to predictors. A zero-information sensor yields G0; full information bound EVPI holds. Product internal source code in quartz/experiments/c20_predictive_value.py; Rust standalone finite-state channel reference for independent numeric parity (Beta formula Rust not claimed).
