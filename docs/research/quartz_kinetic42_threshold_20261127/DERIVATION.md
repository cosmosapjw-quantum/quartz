# Finite threshold action proof
Orient state (a,b) to mover/opponent. v in {-1,0,1}. Define P_t(s)=1[v(s)>=t], t=0,1. Negamax integer inequality gives -v(child)>=t iff v(child)<=-t iff NOT P_(1-t)(child). Hence P_t(s)=OR_m NOT P_(1-t)(child_m), terminal values evaluated exactly. This is null-window WDL recursion. For t=0 and t=1, P1 implies P0. Cache a sound interval [l,u] initially [-1,1], and update l=max(l,t) on true, u=min(u,t-1) on false; interval intersection remains sound. If l>=t or u<t no work needed; else count one uncached predicate expansion (not unique state count), evaluate children; store only completed threshold facts. Immediate win/mandatory-block/double-threat/dead-line K41 lemmas transport because exact, not approximate heuristics. Root (no terminal) action interval [-1,1]; ascending action order, evaluate threshold1 on each action until a win is proved, then threshold0 on each action if all wins disproved. First true in first successful sweep yields smallest-index minimax-optimal action; if no nonloss action, all -1, choose smallest legal. Proof: previous smaller actions disproved at selected threshold, larger actions upper bounded by value 1 or by completed first sweep 0. Stop before computing full action values, except in all-loss or worst-case exhaustive scenarios. For every action interval l_m<=v_m<=u_m; chosen a has l_a>=max_{m != a}u_m. Tie policy: smaller competitor must have u_m<l_a. Return exact action and root value but not unseen action values. Any abort from node budget produces no action recommendation; no unproven decision on fallback. Full-census comparator uses same threshold primitive, evaluates both thresholds as needed for each action, same tie. Node savings not guaranteed pointwise since search order/cache differ.
Regret upper bound: max_m U_m-U_a <= (max_m u_m-l_a)/2, with normalization U=(1+v)/2; max includes chosen. Zero bound iff chosen interval collapses against all others (may be stronger than action proof if own upper unknown; root sweep certifies selected value). After proof, exact regret zero; previously safe finite-vote lock only preserves baseline choice. Decision value of proof can be positive if baseline suboptimal, cost is heterogeneous. For a prospective finite computation budget, expected value = E[regret before - regret after], with CPU, wall, NN rows and predicate expansions separately measured. A fixed 25k cap and <=16 eligibility are experimental decisions, not an optimal dynamic allocator. No universal speed theorem. Same gate and same evaluator isolate policy difference; early paths match until a proof changes recommendation. Even exact minimax ties can differ against imperfect opponent.
