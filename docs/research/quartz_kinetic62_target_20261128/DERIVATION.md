At an eligible H4 occurrence x, fix a=proof-safe H4 move, b=predecision K57 rival and deterministic suffix rho = H4 vs same-model B32. Let V_a=Y(s,a,rho), V_b=Y(s,b,rho), and restricted oracle O=max(V_a,V_b). R_a=O-V_a=(V_b-V_a)_+ >=0. A targeted rule T in {a,b} yields R_T=O-V_T >=0 and gain D_T=V_T-V_a=R_a-R_T. With I=1(T=b), D_T=I(V_b-V_a); hence E[D_T]=E[I*positive gap]-E[I*negative gap], and capture of positive opportunities is separate from harmful switches. Generic H8 may select outside {a,b}, so O-V_H8 is a signed residual, not necessarily regret. If same chosen action and suffix deterministic, outcome and suffix receipt semantics coincide. Full-game utility difference is D - lambda*(own physical calls difference), downstream cost can differ even if local attempt caps match. Restricted oracle is retrospective and never played as a policy.
For each pair edge m, prefix n_m,W_m is from root viewpoint. Reuse existing child and perform exactly two new visits; if child not expanded, its first expansion counts as one visit (not a hidden extra eval). Returned opponent-view values z_1,z_2 enter root-view estimate q_m'=(W_m-z_1-z_2)/(n_m+2). Native proof singleton value used directly; otherwise clip empirical q' to proof interval as a heuristic, not a continuation-value bound. Choose b only if q_b'>q_a'. At most two evals per non-singleton child, at most four logical/physical evals over prefix; no root vote mutation. Terminal attempts may cost zero; cache hits count logical vs physical separately. The estimator mixes adaptive/nonstationary samples; no unbiasedness, posterior-calibration or BAI theorem is asserted. Generic H8 can allocate all visits to one branch; equal visit budget does not imply equal cost or depth.
Population strata c have N_c known and n_c selected uniformly without replacement. HT mean is sum_c(N_c/N)*sample_mean_c, unbiased for fixed occurrence population. Var estimator sum_c (N_c/N)^2*(1-n_c/N_c)*s_c^2/n_c; not inference for future occupancy. Counterexample: pair a,b both score 0; generic H8 selects c with score 1, restricted residual -1. Another: all four new leaf samples favor b yet V_b<V_a due to evaluator bias; finite samples cannot guarantee improvement. No tuning on K61 or K62 heldout.
