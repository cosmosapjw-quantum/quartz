# Protected computation allocation
Let B be stage NN budget, r in [0,B-1] protected optional-call quota, F_b=B-r and F_v=r; pending reservations R_b,R_v and consumed calls C_b,C_v. Before release, F_b+R_b+C_b=B-r and F_v+R_v+C_v=r. Base claims one token before selecting; terminal or rejected ticket refunds it. V claims k in {0,1,2} nonterminal child evaluations together from F_v, else skip. No double use. At quiescent boundary R_b=R_v=0, transfer F_v to F_b, set protected mode off, then continue normal common pool until exhausted or total visit cap. Invariant B=F_b+F_v+R_b+R_v+C_b+C_v, final C_b+C_v<=B. If r=0 use original common pool, not zero optional quota. Releasing unused protected capacity restores feasibility of common-pool drain, not guaranteed equal visits or value. During protected phase base cannot spend F_v; if a valid V requiring k<=r appears before other V claims deplete the quota, the claim is possible regardless of base reservations. This is conditional, not starvation freedom for every V opportunity. At B=8,w=8 common pool can legally reserve all tokens before refinement begins; r=2 prevents this first wave from consuming those two tokens for base. r may reduce base search diversity. Nonterminal V all-or-none reservation avoids partial change of value target. Terminal and ticket refunds only base pool. Atomic free and quiescent mask switch; separate receipt lock K25; no proof of full race freedom.
Compute action a=(mask,worker,wave,r), stage state H includes actual tree, receipts and counters, pending zero at controller decision. Price lambda=.002 utility/NN for bounded assay. q2(H1,a)=E[U(d2)-lambda K2|H1,do(a)], q1(H0,a)=E[max_b q2(H1,b)-lambda K1|H0,do(a)].
