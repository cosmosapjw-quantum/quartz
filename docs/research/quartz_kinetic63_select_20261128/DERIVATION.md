For fixed state x and deterministic H4-v-B32 suffix, let Y_a,Y_b realized continuation scores for the candidate pair. STOP chooses a, FREE selects f(x) using already observed prefix values, TARGET selects t(x,z) after at most four further evaluator calls. For c in {S,F,T}, define G_c=Y_c-Y_a, K_c=C_c(root)-C_S(root), U_c=G_c-lambda K_c. Then G_T-G_F=Y_T-Y_F, and U_T-U_F=Y_T-Y_F-lambda K_T since K_F=0. For pair oracle O=max(Y_a,Y_b), G_c=R_S-R_c, R_c=O-Y_c>=0. If f=t then incremental computational value relative to FREE is zero in realized score but may have positive cost; if f!=t, realized gain can have either sign. This separates existing-information decision rule from additional information acquisition. No division by zero for FREE: use net value rather than regret/cost ratio.
FREE uses q_m=clip(W_m/n_m,L_m,U_m) when n_m>0, or singleton L=U as an exact minimax surrogate; else unknown. Switch iff both defined and q_b>q_a. Proof screens only legal nondominated alternatives; minimax bounds do not constrain fixed-policy score.
For cell c with N_c occurrences and n_c SRS observations, p_c=N_c/N, estimated mean u_cj and k_cj. Optimize max sum p_c u_c,j(c) subject to sum p_c k_c,j(c)<=1.5 and supported action. STOP feasible with zero. Enumerate 3^6 deterministic tables exactly; tie-break smaller cost then lexicographic code. This solves finite empirical restricted class, not global optimal metareasoning, not calibrated posterior. For any fixed table, design-unbiased estimated population means; selection using same data introduces optimism. Constraint on H4 occupancy not preserved under changed policy, so evaluate whole games separately. No per-root iid or new-model inference from finite population.
