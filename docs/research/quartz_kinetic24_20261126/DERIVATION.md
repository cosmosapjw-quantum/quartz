## Identity and information
For fixed evaluator and rule/representation/epoch, let atomic evidence id l=(exact leaf board, side, kind), payload y_l in [-1,1] leaf perspective. A child state s has fixed ply parity relative to every descendant leaf, so y_{s,l}=(-1)^(depth(l)-depth(s)) y_l. At each incoming context e=(exact parent, action) store a finite map E_e: id->raw payload, separate from path N/W/M2. For a fixed child, two such maps merge by compatible union; disagreeing payloads invalidate deterministic identity, not silently average. Union associative, commutative, idempotent. New transferable evidence to e at a visit is E_other\(E_e union {current leaf}), not multiset of visits. A different identity is not proof of independent likelihood or same target utility. Current terminal observation stays exact at backup; no blend on terminal sample. Prior terminal evidence may appear in heuristic context means.

## Exact transport versus heuristic
For exact interval proofs with common state identity, intersection [max lower,min upper] is idempotent and preserves coverage if all bounds valid; empty intersection falsifies input assumptions. On a finite alternating game DAG, Bellman V(s)=max_a -V(child) is nonexpansive in sup norm, composition preserves bound even along shared paths. Root change from one improved subtree cannot be obtained by adding visit impact over all paths; local min/max active choices determine actual effect. This is not a calibrated global VOC from approximate Q values. The actual algorithm here keeps N/W/M2 accounting per traversed edge, not posterior precision; computes raw other-context mean vs mean of compatible unique leafs not already in own context/current observation, applies original bounded .25 blend on nonterminal path backup, no proof manipulation. Both variants still heuristic biased readouts because adaptive sampling distribution differs and shared evaluator error remains. Use explicit data to compare against ordinary.
