# Four-axis metareasoning and interaction
At computation state H, feasible typed operator tuple z=(zS,zX,zV,zB) induces a transition kernel K_z on search states via ordered composition (selection and widening interleave; leaf evaluation precedes backup). STOP has payoff M(H)=E[U(a(H))|H] under a specified utility belief and zero extra work. For deterministic costs c_z and finite discrete residual resource b, V(H,b)=max{M(H), max_{z:c_z<=b} E[V(H',b-c_z)|H,z]}; for random costs need explicit budget transition, admissibility and overrun convention. Myopic signed gain for fixed actual root decision rule is E[U(a(H'))-U(a(H))|H,z], which can be negative. Bayesian reoptimized max of posterior means has nonnegative expected information value by Jensen only when old decisions remain feasible, posterior updates are coherent and the action rule maximizes that posterior; do not assume it for approximate MCTS. Net gain subtracts lambda c (lambda utility/us). Gibbs distribution over feasible tuples uses positive prior Pi and exp(beta net gain), log-partition identity as prior NN04; not independent axes unless score and feasible set factorize.
Factorial attribution: for D={S,X,V,B}, f(A) is paired expected terminal utility (or signed gain, or measured cost, never conflated). Define m(T)=sum_{A subset T} (-1)^(|T|-|A|) f(A). Then f(A)=sum_{T subset A} m(T) by binomial cancellation; joint change f(D)-f(empty)=sum_{T nonempty} m(T). Shapley contribution phi_i=sum_{T containing i} m(T)/|T|; sum_i phi_i=joint change. Main isolated effects m({i}) omit interactions; XOR example f(empty)=f(S)=f(V)=0, f(SV)=1 demonstrates joint gain without marginal gain. Attribution is descriptive for specified intervention settings, not universal causal independence. Estimate per paired root and seed then average by family, retain negative interactions.
Constructive local operators: S uses D_KL(smoothed visible visit proportions || smoothed normalized visible neural prior), c_local=c0[1+0.5 D/(1+D)] in [c0,1.5c0]; no root-only coefficient or probability of flip claim. X uses native progressive widening k(N)=max(1,floor(2 sqrt N)) with existing depth scaling, augments width to first sorted candidates covering at least .75 normalized prior mass, never hides already materialized edges. This is a prior-mass heuristic, not uncertainty confidence coverage. V: base NN (p,v), when |v|<=.65 and >=2 legal moves, evaluate two highest-prior children with same frozen NN or exact terminal outcomes; v'=0.5 v+0.5 max(-v_child) on that subset. Priors unchanged, exact terminal leaf bypasses; constrained subset and approximate NN can bias either direction. Count actual extra NN calls. No claim minimax bound from estimates. B: raw child-perspective path return x (negamax signs), propagated y. Store previously observed raw returns by child identity and incoming parent identity/edge index. If another incoming context exists, use its aggregate raw mean m; else own past raw mean. With n prior observations, eta=min(.25,n/(n+4)); new child return (1-eta)y+eta m, then flip sign at parent. Exact terminal leaf paths pass unaltered at every edge. Append exactly one raw observation per traversed edge; do not add pseudo visits or assume independent samples. Separate other-parent merge and same-edge temporal smoothing. Bound |new-y|<=2 eta, values in [-1,1], sign-equivariant when all values flip. At depth L, comparing to raw leaf negamax with bounded m, |error at root|<=2[1-product_l(1-eta_l)] by recurrence e_l<=(1-eta_l)e_{l-1}+2eta_l. This is an algebraic perturbation bound, not bias-to-true-WDL guarantee. B serializes Welford n/W/M2 updates within research engine, preserves VL removal and one visit per edge, uses true observed incoming identities instead of legacy repeated-edge RTT proxy. Other contexts may be correlated or different continuation policies; shared raw means are heuristic regularization, not independent evidence. Terminal proofs, game legality and state hash semantics mandatory.
