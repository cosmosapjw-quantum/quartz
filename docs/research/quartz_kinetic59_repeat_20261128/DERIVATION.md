Absorb terminal states and extend to fixed T<=45 plies with zero future cost. Define reference V_F(s) = expected terminal score from first-only policy F, score in [0,1], terminal V_F=Y. Let R be repeat policy. For each nonterminal state define A_F(s,a)=E[V_F(s')|s,a]-V_F(s), with a a search/commit operation including first-attempt flag update. Then E_R[Y]-E_F[Y]=E_R sum_t A_F(s_t,a_t), since conditional expectations telescope and both policies start at same s0. Baseline moves contribute zero when policy/state transition agree. First-only matched data identify effects only at its visited states, not R occupancy. Conditional per-root harm at R-visited states gives lower bound -sum E_R[( - A_F)_+], not an independence assumption. Coupling bound |E_R Y-E_F Y| <= Pr(first trajectory divergence), not number of stops; two benign-looking local changes can interact.
