# R5. Finite preservation lemma, proof, and its scope

**Lemma (resident mask expansion preserves historical edge statistics):** Let one MCTS root node `r` have a fully allocated immutable edge list `E=(e_1,…,e_m)` for every legal move `A(s)`, `m≤7`. Let `M_0⊆M_1⊆A` be nonempty selection masks, updated only between serial completed iterations after first stage `t_0=8`. Root-edge per-action counters `N_a,W_a,V_a` are mutated only by backup of a selection path (and any virtual loss is fully removed at completion). At the instant `M_0→M_1` by atomic mask store with no tree reconstruction, (i) root node and all edge identities remain unchanged; (ii) for every a, `(N_a,W_a,V_a)_after=(N_a,W_a,V_a)_before`; (iii) newly enabled a∈M1\\M0 satisfy N_a=0 provided they were disabled from search start; (iv) `Σ_a N_a=N_root` whenever each completed iteration has exactly one root edge and increments its own visit and the root visit once; (v) `P(a|s)` and child TT keys remain original full-game data. This is an *implementation-invariant lemma conditional on mutation ownership*, not a proof of algorithmic optimality.

**Proof:** (i) a gate is a scalar state variable read by root selection, not a node replacement, edge insertion or transposition-table rekey; all references remain. (ii) by assumption the store writes no counter, and there is no in-flight simulation, so equality holds at the instant. (iii) the first-stage selection never takes edges with inactive bits; their counters start at zero, and only selected paths are backed up. (iv) by induction: initially both totals zero, and a completed iteration increments exactly one eligible root edge and N_root by one, preserving equality; mask update adds zero to both. (v) neither edge prior nor root-state/current-player/child move is modified by the gate. QED.

**Necessary assumptions:** a fixed full-legal candidate list and preallocated root edges; masks apply **only at depth=0**; no process has a pending virtual loss on the root during changes; a new edge cannot silently inherit a differently keyed TT node; no root promotion; and no index≥64. These must be directly checked in Rust, not inferred from the abstract proof.

**Counterexample to a stronger claim:** Preservation alone does not imply positive exact-WDL gain. At N_root=8, priors `P=(1/2,1/3,1/6)`, old selected first-arm visits `N=(8,0,0)`, Q estimates `(2/5,0,0)`, c_PUCT=2, no active noise. `score_1=2/5+2√2/9`, `score_2=4√2/3`, so upon activating action2 it is preferentially selected even if its exact utility is worse than action1. One can assign `U_1=+1,U_2=-1` consistently with the absence of any oracle restriction on PUCT. Thus no theorem `Reg_after≤Reg_before` follows. This counterexample concerns algorithmic scoring, not an actual sampled Connect4 root.

**What is NOT proved:** almost sure convergence at finite24, Bayesian expected VOC gain, improvement over all-legal 24, higher Gomoku/Elo playing strength, effect on human attention. These are empirical or separate mathematical obligations, not an incomplete part of this conditional lemma.
