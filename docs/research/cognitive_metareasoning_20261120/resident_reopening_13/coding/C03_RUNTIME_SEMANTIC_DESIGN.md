# C3. Numerical representation and finite bounded checks

**Root mask semantics.** Legal root action ids `0≤a<7`, `mask(A)=Σ_{a∈A}2^a` as u64, `M=0` sentinel means **all** legal actions enabled. Must never treat an empty API input as sentinel. Given validated inputs `L` legal, `mask(A)&~mask(L)=0`, `mask(A)≠0`. Monotone after observations: `old!=0 ⇒ old&new==old`. If root has already completed an iteration under unrestricted `old=0`, later restriction is forbidden; no backward structural mutation. No bit shifts outside [0,63] even for other games. A masked search may later enable all legal bits without switching to the zero sentinel, allowing stable audit of a transition.

**Engine-level mathematics:** original edge prior `P_a`, old `N_a`, `W_a` remain unchanged when mask updates. At root selection, for `a∈M`, `score_a=Qhat_a+c_PUCT P_a sqrt(N_root)/(1+N_a)`. Compare only active edges, with **original full-game prior, no active-set renormalization**. This deliberately differs from COG03-12 masked root prior recalculation. At depth>0, no mask. `best_move` derived from root visit counts after ≥8 completed selections, so disabled zero-visit moves cannot win the root decision; unit test checks edge0 disabled while other moves active.

**Finite algebra checks:** `mask({2,3,4})=0b0011100=28`; after enabling `{0,2,3,4}`, mask=29, subset true. Every nonempty subset of seven source columns can be encoded as unique u64; all 127 masks are finite and no other game move semantics altered. `coding/mask_semantics13.py` enumerates these finite cases and exact subset counts separately; this tests the mathematical contract, **not implementation correctness**.

**Physical resource:** resident root candidates/slab for all legal actions created once before first8, so root setup upfront may cost at least as much as all-legal baseline; memory savings not claimed. Total measured request excluding model load `T=full-model-prior_ranking+one_root_setup+first8+oneply_probe+mask_activation+next16+formatting` in real microseconds, plus optional `pure_search_us` and completed NN forward-call count. Aiming for equal root visit counts (24) does **not** prove equal time; actual cost gate is `|T_reopen-T_full|/T_reopen≤.10` separately per cohort/mode.

**Numerical precision:** f32 P and Q (PUCT), f64 accumulated W in atomics. Exact oracle is signed WDL integers; no method converts a low-prior move's one-ply safety into solved game utility. MC error at only24 root visits can be substantial. Pending VL must be absent during serial checkpoint change. Edge N/W/M2 measured before/after store with exact representation (N integer, W/M2 float), not approximate guess.

**Output proof obligation:** snapshots before and after mask store must have equal root pointer identity, TT hash, edge priors, N/W/M2 and eval calls; new N starts0; after continuing Nroot=24 and sum root edges Nroot. Physical elapsed includes compulsory full upfront materialization. Verified source snapshot not only method name.
