# R3 | Target probability law and scientific status

Let independent source parent G specify a decision environment and latent utility parameter theta. An initial computation history H0 gives terminal action a0 = Bayes best given current evidence and task-defined utility. The available extra meta-action c has a predeclared sample count, observation law L(y|theta,H0,c), measured post-initial resource cost C>=0 microseconds, and yields a1. Define X=phi(H0)=[normalized top-two expected terminal utility margin, log1p(|A|)] from information available before continuation. Y=1[a1 != a0], Z=U(a1,theta)-U(a0,theta)∈[-1,1] for utility-normalized tasks.

Joint law P_D(Y,Z,C | X,c) is the target. The decomposition q_D=P(Y=1|X,c), m_D=E[Z|Y=1,X,c] (for q>0), g_D=q_D m_D and net gain n_D=g_D−lambda E[C|X,c]. A binary flip label alone is insufficient to infer sign. Independent true task utility labels are supplied only offline for evaluation, not consumed by predictor. Clock C is realized additional work duration, distinct from C18's *total* 20ms Rust search and not interchangeable without scope.

Two source domains: BETA_ARMS with independently sampled latent Bernoulli arm means drawn from Beta(2,2), exact Beta(2,2) posterior update after actual draws; FINITE_SENSOR with 4 hidden discrete world states, public payoff matrix U(theta,a) with 3 terminal actions, noisy observation likelihood known for each state, exact Bayesian posterior on repeated additional categorical sensor queries. Both are non-game and have a mathematically defined utility. Posterior regret may be computed offline via true theta, while online forecasts receive only generic first-action margin and |A|.

Bayes EVOI (gross expected gain) is nonnegative conditional on *complete calibrated* current posterior/history and an optimal posterior action; realized Z can be negative. On a coarser feature projection X, signed utility can be estimated from sample groups but the conditional law depends on source distribution. Cost exchange lambda>0 has units terminal utility per microsecond. Do not silently use post hoc oracle labels to choose samples or change source-specific priors.
