# Literature and exact sources
Czech, Korus, Kersting, Improving AlphaZero Using Monte-Carlo Graph Search (ICAPS2021), https://scispace.com/papers/improving-alphazero-using-monte-carlo-graph-search-1ee1q4ws3y, abstract: replace tree by DAG, share information across subtrees; not mere inference caching. KataGo graph search documentation https://github.com/lightvector/KataGo/blob/master/docs/GraphSearch.md, discussion of transposed C and parent A: sharing node counts without appropriate backup can produce stale/biased parent estimates. Speculative Monte-Carlo Tree Search, NeurIPS2024, https://proceedings.neurips.cc/paper_files/paper/2024/file/a19940b01b77b6acd41ff8b32b334e7c-Paper-Conference.pdf section4.3: hash NN inputs, reuse predictions including speculative discarded moves; latency benefits are implementation-dependent. K52 native source and actual receipts are authority for exact cold operator. No transfer of Go speed numbers or graph-search correctness theorem. Cache scope fixed model and exact input, not D4 symmetry or shared node statistics.
