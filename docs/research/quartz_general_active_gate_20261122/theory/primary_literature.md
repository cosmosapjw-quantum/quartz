# R02 | Prior metareasoning results and source reuse

Hay, Russell, Tolpin, Shimony, Selecting Computations: Theory and Applications (UAI 2012, https://arxiv.org/abs/1207.5879): Theorem 4 characterizes expected terminal utility minus cost per computation, Theorem 5 bounds expected compute count by EVPI/c, and Section 5-6 considers upper VOI bounds and stopping. Thus metalevel upper-bound screening is established literature, not original to C22. Callaway et al., Learning to select computations (UAI 2018, https://arxiv.org/abs/1711.06892) estimates metareasoning decisions with VOI1/VPI features and includes its own computational overhead in empirical evaluation. Lin, Kolobov and Kamar (2015, https://arxiv.org/abs/1505.00399) values nonzero planning time. Sezener and Dayan (2020, https://proceedings.mlr.press/v124/sezener20a.html) distinguishes static and dynamic computation in MCTS.

C21 authoritative source src/bin/quartz_c21_fast_evsi.rs is exact within independent Beta posterior arms; C20 src/bin/quartz_c20_shadow.rs implements fixed-hidden-state sensor posterior value. Neither establishes calibrated likelihood for actual adaptive neural MCTS. C22 constructs a bounded source-correct in-process active policy, not novel Bayesian decision theory. Reuse prior model only with explicit parameter/action/payoff correspondence and unchanged files.
