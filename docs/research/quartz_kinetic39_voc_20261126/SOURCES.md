# Primary literature and transport
- Hay, Russell, Tolpin, Shimony, Selecting Computations: Theory and Applications (2012), https://proceedings.mlr.press/r10/hay12a.html and https://arxiv.org/abs/1207.5879; Bayesian selection and metalevel stopping/VOI under assumptions, finite sampling bounds, nontermination counterexample. Use objective, not generic finite PUCT guarantee.
- Tolpin & Shimony, MCTS Based on Simple Regret (AAAI 2012), https://arxiv.org/abs/1207.5536 ; actual final choice accrues reward, VOI proxy combines probability of decision change and conditional gain; interior search nonstationary, approximate estimates not calibrated probabilities here. Exa primary-paper excerpt §VOI-aware Sampling.
- Sezener & Dayan, Static and Dynamic Values of Computation in MCTS (UAI 2020), https://proceedings.mlr.press/v124/sezener20a.html ; static/dynamic VOC and greedy optimality under assumptions, not guarantee of monotonic realized finite MCTS utility. SciSpace record and publisher abstract, original formula excerpts from K38.
- Callaway et al., Learning to select computations, https://arxiv.org/abs/1711.06892 ; VOC net of computation cost as metalevel objective (Exa Eq. 1 excerpt). Finite empirical table here is not globally optimal belief-MDP solution.
- Parallel source search independently located MDP metareasoning under uncertainty (https://ijcai.org/proceedings/2015/229); domain differs, use only cost-vs-decision distinction.
No novelty or asymptotic optimality claim. Original project evidence: 15f3a198 initial README and QUARTZ_THEORY §§1–3, 7241ad0c frozen THESIS, K33/K37/K38 reports.
