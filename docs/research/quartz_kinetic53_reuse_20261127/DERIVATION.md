# Reuse and sequential interventions
For fixed deterministic evaluator F(theta,s) and exact ordered legal action set, cache F by full key (a,b,p,legal) within one request, fixed theta and precision. Induction on request trace: equal initial search state implies identical query key; cache returns the identical stored value, next node/backup unchanged, including tie handling. Logical queries L, physical forward rows M, hits H, L=M+H; within cold per-request cache M is number of distinct keys. An inference hash hit is not a visit or a saved tree iteration. Compare actual forwards and trace, not claimed wall speed. If evaluator has history, hidden state, stochasticity or batch-dependent numeric results, premise fails. No symmetry quotient.
Reuse operator initializes a missing child, otherwise keeps its existing internal statistics. Root edge receipt is held fixed; perform k=5 new child-root backups x_j, raw parent value -sum(x)/5, not pooled old+new. If child already expanded with n visits and sum w, post sum w'=w+sum(x), n'=n+5; -sum(x)/5=-(w'-w)/5 in exact arithmetic. Pooled mean differs by n/(n+5)*(old_mean-new_mean); old root visit count includes initial expansion, so child n=max(root_edge_n-1,0) for nonterminal. Call count for expanded child 5-terminal_leaves, otherwise 6-terminal_leaves. Two actions <=12 calls; when both expanded and nonterminal <=10. Even fresh-only statistic has new sample policy depending on old tree; not semantic equivalent to cold. Preserve parent proof dominance and point intervals; never modify original root vote certificate. Counterexample: same evaluator with prior tie and different prior visits changes PUCT argmax, hence new sample law; cache does not.
Sequential policy: let pi0 never intervene, pi1 intervene first eligible, piM intervene every eligible. Score contrast telescopes Y_M-Y_0=(Y_M-Y_1)+(Y_1-Y_0) per matched episode. This is NOT the sum of independent local gains; subsequent eligibility is policy-dependent. pi1 and piM same prefix through first action; until second intervention they have identical paths, so episodes with <=1 reached event under piM exactly match pi1. For REUSE vs COLD common pre-event state, cost difference = local difference + signed downstream Q/B. Compare joint score/cost, ratios only for positive denominators on all resamples; no conditioning on changed action for causal selection.
Rapfi targeted: Q96 raw visit leader and proof replacement differ potentially; use actual selected incumbent a, best nonloss rival b by later candidate tie. If upper(a)=-1 skip (all alternatives may be proved losses); if lower(a)>=upper(b) skip. At final Q96 root with d<=8 and disagreement with prior leader, child engine at s_i with same Rapfi evaluator and frozen engine config. First evaluation + five visits (one NN per nonterminal leaf), all edge w sum child perspective, negative mean to parent. Exact point/terminal values no evaluator calls. Keep base Q96 visits and calls separate from optional <=12 calls, bridge total=base+extra. Exact root lock applies to vote winner, not new target-selected action. This is finite opponent computation operation, not proven minimax improvement.
