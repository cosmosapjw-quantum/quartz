# C3. Numerical and algorithm design (pre-label lock)

Feature dimension 13, range [0,1]. Cross-platform Python and Rust implement identical integer geometry and hypothetical line-run/windows. Explicit 64-bit/float64 NumPy training, float32 Rust inference. For each state choose full legal softmax with exp(logit - max_logit), check finite denominator. Logistic objective L(theta)=(1/n)sum_i[-log p_theta(y_i|s_i)] + .005 sum_j theta_j^2 (lambda .01). Gradient=sum_i[sum_a p_i(a)phi_i(a)-phi_i(y_i)]/n+.01 theta. Hessian=feature covariance/n+.01 I positive definite, hence damped Newton with Armijo backtracking converges to unique minimizer under numerical tolerance; log iterations and gradient norm. Fixed init zero and <=70 Newton updates. Validation loss and accuracy are diagnostic only; no test-informed hyperparameter tuning. Check teacher move legal and source terminal-free.

Primary MCTS equal-CPU criterion: each request has fixed target 20ms (not equal visits), timed by Rust Instant after model JSON load but before policy inference/root setup, and ending after root search, prior, mask, probe. Count legal actions, root node pointer identity, 8 initial visits, preserved priors/N/W/M2 on reactivation, full elapsed microseconds and actual N/evaluator calls. Integrate a bounded incremental FixedIterations loop with a 1-visit quantum near budget end (avoid large overrun) and maximum safe 2048 visits. Compare learned_gated vs learned_all_legal at same theoretical target and check *achieved* wall-CPU mismatch per stratum <=10%. Uniform_full is an additional factorial control. If CPU budget cannot be reached due cap or runtime instability, label COST_NOT_MATCHED.

Sampling: fixed pre-registered 128 train,32 validation,48 natural heldout,16 separate tactical diagnostic (not IID). No C14 roots in any fit/evaluation. Freeze sources and policy-controlled data generation code BEFORE reading teacher test labels. Avoid win-move-induced latency bias by profiling each stratum separately. For root label y chosen by finite-time Rapfi and model action a, teacher-agree is a proxy with no exact WDL/Elo connotation.

Expected uncertainty: model is strictly policy-only (not a deep trained value net), teacher labels depend on finite search, repeated transformed boards not independent. Numerical loss/finite-difference tests, Python-vs-Rust feature/logit parity, source SHA and replay legality are acceptance conditions.
