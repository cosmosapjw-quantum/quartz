# Coherent conditional transition model
Fix F at prefix, finite panel A={0,1,2}, fixed D_i=U_i-U_0, D_0=0. Let c denote an admissible compute channel and J_c(s,z)=P(D=s,Z_c=z|F) with fixed latent marginal p(s)=sum_z J_c(s,z) shared by every channel. This expresses no change of true game utility under computation. Set H=sum_s p(s) max_i s_i, m_i=sum_s p(s)s_i, V=max_i m_i, R=H-V. For outcome z let t_i(c,z)=sum_s J_c(s,z)s_i, pi_z=sum_s J_c(s,z); conditional mean t_i/pi_z for pi_z>0. For zero mass use arbitrary readout and zero contribution. Then V_c=sum_z max_i t_i(c,z), expected terminal panel risk=H-V_c. Delta_c=V_c-V=E[R(F)-R(F,Z_c)|F]. Sum of maxima >= max of sums gives Delta_c>=0; max expectation <= expectation max gives Delta_c<=R. Equality at zero if a common pre-optimal action attains conditional maximum for all positive-mass outcomes, including ties. This is a coherent model identity, not empirical proof of gain. Shared p ensures comparisons cannot benefit from a spurious prior shift. Unlike K18 separate fits, sum_z pi_z E[D|z,c]=m for every c exactly. If Y is obtained from Z by a stochastic garbling independent of D conditional on Z, same prior and action set, V_Y<=V_Z by convexity/tower; no claim N/BAL/EXP are ordered by garbling.
For actual selected a_c(z), signed improvement over d0 is G_c=E[D_{a_c(Z)}-D_{d0}|F]; it can be negative for an approximate model. Decompose G_c=P(g>0)E[g|g>0]-P(g<0)E[-g|g<0]; flip rate alone is not gain. For fixed baseline Bayes d0, optimal channel readout gives Delta_c. Cost C_c measured in ms, lambda utility/ms, myopic net Delta_c-lambda E[C_c|F]. STOP has zero incremental search cost and Delta=0; metareasoner overhead itself costs, so stopping inside a model is not free relative to ordinary search. If all myopic net<=0 stop only in one-step option set, not global Bellman optimum; XOR example two observations each uninformative but jointly reveal binary latent state. VPI upper bound R. Full legal regret additionally includes omission relative to same fixed panel, not reduced by this model.
Computational law: paired TRAIN scenarios j with common prefix features x_j (six entries: for both challengers, score gap/2, visit-fraction gap, prior gap), D_j on 19 states, each native channel c observed response z_jc in {0,1,2} = final shrunk-score argmax on same panel, and actual post-prefix phase-wall time C_jc. Weights w_j(x)=exp(-||x-x_j||²/(2h²)); h in {∞,1,.5,.25}. For all channels use J_c(s,z)=(sum_j w_j 1[D_j=s,z_jc=z]+1/(19*3))/(sum_j w_j+1). Marginal p(s)=(sum_j w_j 1[D_j=s]+1/19)/(sum_j w_j+1). Uniform pseudocount ensures identical marginals, positive probabilities. E cost estimated weighted average without pseudo cost; finite positive weights for feature domain.
