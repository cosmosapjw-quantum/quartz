## R03 — Definitions, units and claim separation
Let grid side m, n=m^2, and L_D have diagonal4 and -1 at each existing north/south/east/west neighbour, with zero Dirichlet exterior. A=I+rho L_D, rho>0. Thus v^T L_D v is the sum of interior edge differences squared plus boundary-edge v_i^2, so A is SPD. Gershgorin gives 1<=lambda(A)<=1+8rho. These conservative endpoints avoid numerical eigenvalue assumptions.
Each of K=3 actions has public b_a and unknown-to-controller q_a=b_a^T A^{-1}b_a. A public exact power-of-two scale S >= max_a ||b_a||^2 normalizes utility u_a=q_a/S into [0,1]. The scientific task is to select an action, not reconstruct an accurate full solution field. Nondimensional screened diffusion is the computational model; no c,hbar,k_B convention is changed or suppressed in a physical claim.

## R04 — Candidate constructions and discriminating predictions
A: retain exact Bayesian EVSI from C22. Appropriate if observation law and task payoff model are known; expected-model arithmetic can dominate cheap task cost.
B: compute deterministic residual enclosures and STOP upon strict action separation. This requires known operator bounds but no learned observation law. Under valid intervals it certifies the exact optimal action.
C: epsilon-regret stopping uses max_a U_a-L_i<=epsilon. It is a useful cost-aware extension, but C23's primary implementation uses strict zero-regret separation; no price fitting or approximate safety claim is needed.
Chosen B compares NEVER (initial work only), ALWAYS (same fixed remaining CG work), CERT_ONCE (one initial check, otherwise identical continuation), CERT_BLOCK (recheck after fixed useful iteration blocks), and a conventional residual-tolerance solve comparator. A block gate may save more work but pays repeated enclosure costs.
Both certified policies, when not certified, return the same final variational-score argmax as ALWAYS after identical fixed iteration states. A certified early exit instead returns the mathematically best true action; it therefore cannot lose true utility against any ALWAYS outcome. Do not claim arbitrary future approximate argmax invariance.

## R05 — Constructive proof and executable interval rule
Write x*=A^{-1}b and e=x*-x. Expanding q-ell gives (x*-x)^T A(x*-x)=e^T A e. Since r=Ae, q-ell=r^T A^{-1}r. Spectral diagonalization then yields ||r||^2/beta <=q-ell<=||r||^2/alpha. This is valid for arbitrary x, regardless of CG orthogonality or residual monotonicity.
With S common and positive, L=max(0,(ell+||r||^2/beta)/S), U=min(1,(ell+||r||^2/alpha)/S) enclose u. Each valid bound may be intersected with its historical bounds: Lbar=max(Lbar,L), Ubar=min(Ubar,U); the intersection contains the same fixed u. Empty intersection is an error, never a reason to widen tolerance.
If Lbar_i>max_{j!=i} Ubar_j, then u_i>=Lbar_i>Ubar_j>=u_j for all competitors; i is uniquely optimal. If future choices use argmax historical Lbar, this choice remains invariant since Lbar_i only rises and all competing future lower bounds remain <=their true u_j. No such invariance is asserted for arbitrary approximate-score selectors.
C23 finite-budget corollary: on strict certified exit, select i. Otherwise, after exactly the baseline's solver work, return the same final ell argmax with deterministic lowest-index tie breaking. At every input certified exit has maximal true utility, and noncertified completion has identical state/action to ALWAYS; therefore gated true utility is pointwise no lower than ALWAYS. This relies on identical unperturbed solver updates and valid outward bounds, not on a population model.
Regret bound for any action i: regret(i)<=max(0,max_{j!=i} Ubar_j-Lbar_i). A future computation's utility benefit cannot exceed this bound. Comparing it with lambda times a guaranteed future-cost lower bound is valid; a fitted clock median is not such a guarantee. A strict zero-regret certificate needs no price estimate. Sunk evaluator costs are included once in ex-ante total elapsed cost and excluded from future continuation decisions.
Floating-point construction: regard all stored f64 inputs and iterates as exact real numbers. For each arithmetic operation, apply next_down to the computed lower endpoint and next_up to the upper endpoint; multiplication takes the min/max endpoint products; square uses zero as lower bound when the interval spans zero. Outward interval stencil yields Ax, then true residual and residual norm squared, and interval ell=2b.x-x.Ax. Positive division and clipping against proven [0,1] preserve containment. Induction over these finite operations proves enclosure under IEEE binary64 operations; reject nonfinite arithmetic. No empirical padding epsilon or fast-math reassociation is used.
