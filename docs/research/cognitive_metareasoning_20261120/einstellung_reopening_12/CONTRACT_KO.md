Parent source `6dbdcaeab28b2325fbd7f0a0326c51b214b339f3`. Dedicated research branch `research/quartz-cog03-einstellung-reopening-20261121`. CPU-only and no mutation to original developer worktree.

**Primary scientific question:** When a real QUARTZ MCTS root is artificially constrained to the top three CPU-evaluator-prior moves, can independently computed legal-game *one-ply tactical evidence* induce the root search to **reopen initially omitted low-prior candidates** and improve the selected action's exact Connect4 win/draw/loss utility at comparable physical CPU cost? This is an **engineered candidate-attention-fixation perturbation**, not demonstrated human chess Einstellung, and not a new progressive-unpruning theory.

Definitions: legal root actions `A(s)`, learned or uniform evaluator priors `p_E(a|s)`. Order by descending prior, ties by distance to center column3 and then column. `A_0(s)`=top three legal actions, `A_{out}=A\A_0`; previous full game legality and rules remain unchanged. First root MCTS search of eight iterations is run on a `Connect4` clone restricted to `A_0`. The exact external oracle never enters any prior, mask, or trigger.

Define **observed fixation** `F=max_a π_8(a)≥0.5` on the restricted root. Let `a_8` be the chosen masked-root best move. Independently probe *every legal root action* by Connect4 rules only: (1) immediate win `w(a)=state.is_winning_move(a)`; (2) if not immediate win, whether opponent has an immediate winning reply after playing `a`, `v(a)=exists b legal(s·a) with is_winning_move_{s·a}(b)`. The second is tactical vulnerability, **not game-theoretic minimax**. At first checkpoint, allow reopening if `F` and at least one initially omitted action is immediately winning, OR `F`, `v(a_8)` and an omitted non-losing-one-ply action exists. Up to two omitted actions reopened, ordered immediate win first, otherwise highest original prior among safe, deterministic center tie. All thresholds top3/8/16/.5/max2 and evidence definitions are locked without reading new-test oracle results.

**Implementation choice:** the existing MCTS constructs root edge candidates on initial expansion and exposes no live root-edge insertion. Use a **root-only legal-action restriction** on a cloned Connect4 state (only while `ply==restricted_root_ply`, descendant legal moves unchanged), then run a fresh MCTS at the second checkpoint; do not claim same-tree continuation. Every arm has 8 root visits on its own first engine and 16 visits on its own *fresh* second engine, including the sham-closed control; include both engine setup costs, prior evaluation and tactical probe time. No hidden extra search for the reopening arm. `root-forced-win=false`, Dirichlet off, base seed17.

Precommitted six root-search arms:
- `closed_sham`: top3 at first8 and second16, perform same full tactical probe but do not reopen.
- `evidence_reopen`: top3 first8, then top3 plus up to two root moves satisfying the precommitted tactical trigger (or top3 if none).
- `random_reopen`: top3 first8, then same number of omitted moves as evidence would open but chosen by **oracle-blind deterministic hash**, same probe and two-engine 8+16 cost.
- `always_full_reopen`: top3 first8, then all legal root actions second16, sham probe.
- `plain_full`: all legal first8 and all legal second16 (both restarted), same probe.
- `closed_no_probe`: top3 first8 and second16, without tactical probe to quantify the probe's wall-time overhead.

Use actual trained `new_mlp`, `conv` and `uniform` as three separate evaluator regimes. Uniform priors are tied, so label its top3 tie-center policy an *engineered attention gate*, not learned lower-prior suppression. For NN modes, report the rank and value of exact-WDL-optimal initially excluded actions POSTHOC only.

Statistics: external Pascal Pons `S(s,a)` for legal a only AFTER all Rust searches. Exact WDL `u(s,a)=sgn S(s,a)`, `-1000` means illegal column. `R(s,a)=max_{legal}u(s,a)-u(s,a)`. Define *decisive omitted* action as one with WDL strictly greater than the best WDL of initial top3. Report negatives (wasted reopening, selected losing move), failure of trigger, and false positives. A forced-loss root with all legal actions same WDL is noninformative for action-quality recovery.
