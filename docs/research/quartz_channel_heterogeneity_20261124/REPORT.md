## Scientific result
A finite latent-rate mixture gives exact histogram moment update, normalization and posterior utility martingale. Conditional on U and cue, repeated draws are iid only given the fixed latent R; their covariance is Cov(R_y,R_z | U,cue). F freezes the conditional class means after four cue draws, A retains the rate mixture, G freezes unconditional within-depth class means while sharing the initial cue posterior. F/A first observation and subsequent utility posterior coincide; H2 difference arises from repeating the same candidate. Exact counterexample (R05) has H1 and frozen H2 value 1/2 but adaptive H2 value 14/25 at query cost 1/100. This is a theorem for the constructed finite model, not a general performance guarantee. Exact rational checks 2703. Source literature in R02.

Verdict: **ADMIT bounded mathematical mechanism and predictive improvement; REJECT promotion of extra-query policy as an improved deployable controller.** Posterior predictive fidelity, decision improvement, and computational value are separate. The true practical target of the original PRD remains unresolved: equal wall-resource strength, broader games, real MCTS state, FOCUS/EXPAND/MERGE interactions. The limited original game and heldout cohort cannot establish Elo, speed improvement, or universality. C07 training and C08 validation are isolated native binary rather than whole Cargo test suite. Native subagent unavailable; no independent-agent review claimed.

## Next research: decision-value calibration before production integration (CHET-02)
Do not grow H or add more planner gates merely because predictive error decreased. Freeze current negative baseline and keep BELIEF_STOP as strongest comparator. Construct terminal decision-loss calibration for the exact-known versus posterior alternatives, with posterior cross-action dependence explicit when needed. Separate value of initial cue posterior from incremental computation and quantify potential degradation instead of asserting exact non-degradation. For the next dataset, move to existing Connect4 GameState with exact bounded late-game reference and prospective disjoint root-history groups; do not recycle exhausted TicTacToe roots as fresh tests. Train on independent groups, hold out entire groups, calibrate action means/ranking and incremental VOI separately. In native matched wall-time paired experiments, include observation, planning, and decision overhead; use fixed budget and compare strongest no-extra-query baseline, original controller and adaptive candidate. Freeze design before outcomes. Only if there is genuine useful incremental decision improvement under resource constraint should integration of FOCUS with EXPAND/MERGE be investigated; otherwise record the negative result and revise observation/evaluation model. No claim that exact bounded Connect4 is already verified.
