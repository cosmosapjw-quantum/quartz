# Pair-targeted proof and confirmatory design
Let a,b be the two chosen root actions, v_a,v_b in {-1,0,1}. Gain2=v_a-v_b=2[R(b)-R(a)]; same action implies exactly zero. Intersect root intervals with sound new facts. If a known optimal require v_a>=v_b; if b known optimal require v_a<=v_b. The feasible pair set S={(x,y): x in [la,ua] integer, y in [lb,ub] integer, order constraints}; gain interval min/max x-y on S is sharp relative to just these restrictions. Proof: every admissible joint pair is in S and the extreme finite pairs themselves meet all declared pair restrictions. Not a theorem that every pair is realized by a legal board. Tightening either action shrinks S and cannot widen interval. If a=b retain common identity, not independent variables. No claim about finite-opponent utility from minimax gain.
For exact threshold T_t(s)=[v(s)>=t], t=0,1: v(s)=max_m -v(s_m), so T_t(s)=OR_m NOT T_(1-t)(s_m). Terminal WDL exact. Forced block is sound only after checking current player's immediate win; two distinct opponent completion points imply loss otherwise. Dead board exact draw only if neither color has any unblocked win window. Root action value -v(child); query NOT T_(1-t)(child). A true root threshold raises l to t, false lowers u to t-1. All updates valid by negamax induction. If expansion cap trips, root query returns UNKNOWN, previous exact memo facts retained, never infer false. For selected pair run at most two threshold tests per action, t=0 then1, each additional cap100000, shared sound memo, at most400000 new predicate expansions per pair. Cap0 permits memo reuse only; no independent proof of false from exhaustion. Action order fixed a then b (one action if same). Starting action bounds from verified K45 evidence; no other root actions need solving for the two-action difference. For late validation, use 384 historical states and independent full-vector truth only where available. For early facts independent coordinate/terminal-only Boolean minimax, no forced-response/dead-board pruning; if cap censored, classify unverified not incorrect. No use of oracle labels in prospective live policy.
Prospective experiment: fixed cold F7 + L20 + exact late fallback vs B32, compare fixed L32 separately vs same B32; all actual games same evaluator. Q20 safety is empirical, not worst-case theorem. Family is unit: both colors and all fixed checkpoints share openings; bootstrap resample entire families; fixed model panel, do not resample models as if independent.
