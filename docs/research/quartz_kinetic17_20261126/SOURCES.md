# R02 primary-source transfer
- Frazier, Powell, Dayanik, Knowledge-Gradient Policy for Correlated Normal Beliefs, §3 Eq (11), https://people.orie.cornell.edu/pfrazier/pub/Correlated_main_paper.pdf : expected increase in max posterior mean; assumes independent normal rewards and correlated normal belief. Identity generalizes by tower, Gaussian model does not transfer to MCTS.
- Xie, Frazier, Chick (2016), Operations Research 64, 542–559, §2.3 Eqs (9),(10), §3.2 Eqs (16),(17), https://doi.org/10.1287/opre.2016.1480 : VOI of singleton/pair observations, restricted implementation set and cost per sample. Their restricted set comparison fixes set in both terms, unlike actual expansion that changes available recommendation set. No novelty claim for KG or restricted VOI.
- Danihelka et al., ICLR 2022, Algorithm 2 and Eq (10),(11), https://davidstarsilver.wordpress.com/wp-content/uploads/2025/04/gumbel-alphazero.pdf : Gumbel top-m without replacement, sequential halving, completed Q for policy improvement. Not a theorem for deterministic native adaptive MCTS forced pulses.
- Zhao et al., ICML 2023, https://proceedings.mlr.press/v202/zhao23g.html : bracketing sequential halving and data-poor simple regret; stochastic bandit assumptions do not certify MCTS. SciSpace search also found Sagers et al. anytime sequential halving (2024), not relied on for proof.
