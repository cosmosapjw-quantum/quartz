# C02 | Source-only decision / offline task execution interface

Public decision has two task-neutral forms: Beta action posterior pair (a_j,b_j) and extra sample budgets n_j, or finite hidden-state posterior b_theta, observation likelihood L_theta,y, action utilities U_theta,a and extra signal count n. Neither public selector receives hidden theta, actual future observations, final action or realized future CPU cost. C22 imports C21 exact Beta EVSI and C20 finite sensor EVSI code by source module paths without editing those original sources. Cheap support dominance and Cauchy/EVPI bound act first; optionally exact EVSI; paid decision; then simulate only if COMPUTE.

Separate Rust offline task executor receives true hidden parameter and frozen seed, physically draws future outcomes only when the selected action is COMPUTE, else zero draws and a_final=a0. Independent ALWAYS baseline with same seed is actually executed in a different timing scope. Timing record includes cheap gate, exact estimator, native task and aggregate active time; latency measured with Rust Instant on same device. For sensor the fixed theta is shared across all future categorical observations. Source labeled true expected terminal utility after executing action, not one random observed 0/1 reward. No live game SearchPolicy integration.
