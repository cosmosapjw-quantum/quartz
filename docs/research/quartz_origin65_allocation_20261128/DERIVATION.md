## R3-R5
Let legal set A, exact minimax utilities v(a) in {-1,0,1}, validated intervals L_a<=v(a)<=U_a. If all U_a=-1, retain A (certified loss); otherwise retain F={a:U_a>-1}. For a removed arm v=-1, every retained arm has v>=-1, hence max_F v=max_A v. The filter preserves an optimum, not all optimal arms, and does not guarantee preservation of actual finite-opponent continuation utility Y_rho (counterexample: a minimax loss can win against an imperfect opponent). Retain proof-certificate fast path, do not change proof rules. For general dominance U_a<max_b L_b, the maximizing action cannot be a, but avoid adding that intervention here; prior/current WDL intervals usually +/-1.
A root visit uses one evaluator unless terminal or cache hit. Let N_i be completed root visits, W_i sum of backed-up root-view values, P_i frozen prior. At fixed prefix budget h=4: sum_i N_i=h; logical NN=1+h-terminal; physical=logical-cache_hits. Root exclusion changes the selected index before recursion. PUCT score Q_i+2 P_i sqrt(max(1,h_done))/(1+N_i), raw P unchanged; all N,W start zero. For X4, if any unvisited F exists, select maximal P among those (tie smaller action); else PUCT. By induction, distinct F visited = min(h,|F|); when h<=|F| this is maximum possible. This does not optimize regret by itself. Zero visit is unknown, not a measured Q=0 at readout; exact singleton overrides empirical mean. Readout on visited F (or exact singleton) maximizes clipped surrogate q_i=clip(W_i/N_i,L_i,U_i). This minimizes surrogate ranking regret on that subset, not minimax or fixed opponent loss. Incumbent retained via vote fallback only when no value. M4/L4 and MA4/A4 isolate allocation on a fixed root, whole game effects mediated by different trajectories. X4/MA4 isolates coverage scheduling, not increased visit cap.
