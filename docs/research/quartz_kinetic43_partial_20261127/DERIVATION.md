# Partial forcing proof and interval control
Let W(s,d) be a sufficient proof that mover can force a win in at most d plies. Values TRUE/UNKNOWN; FALSE only when the game-theoretic predicate itself is disproved by exact facts (not used for restricted search failure). General three-valued OR: true if any true; false iff all legal children false; otherwise unknown. Negation swaps true/false and leaves unknown. Restricted attacker enumeration leaves omitted children unknown, so cannot disprove a win. Represent unknown as [-1,1] and maintain exact WDL bounds. For alternating negamax, child [l,u] becomes [-u,-l]; max over all legal actions gives [max l,max u]. Sound by induction. Finite depth/node truncation returns unknown, already established facts retained; no partial facts promoted to proof without logical coverage.
For unrestricted k-in-row, define I_A(A,B) distinct empty completion cells for A. A legal placement m either completes line (win), or opponent has immediate win (cannot force a win from this action), or own completion threats after m. If opponent has none and own >=2, every defender reply leaves at least one winning cell; attacker wins within 3 plies. If exactly one q, every defender response except q allows immediate win; q is legal, cannot itself be a winning reply because opponent immediate set was empty. Hence proving W(A+m,B+q,d-2) proves win from m, with d>=3. Induct on depth. At attacker turn enumerate all legal moves with immediate win or nonempty threat; others UNKNOWN. If defender already has a completion, an attacker nonwinning move leaving it cannot be certified. Neither absence of forced line nor budget exhaustion proves loss. For each root action, prove own win by this recursion, or opponent win on successor => action value -1. Common one/three-ply facts exact; full-board draw exact. Distinct cells counted, not windows. Root scan all legal actions; untested [-1,1]. Count root tests and uncached recursive attack calls; line scans and candidate checks separately. Budget exhaustion never exceeds count, may retain prior certified facts.
If some a has l_a>=max_{b != a}u_b, it is minimax-optimal even if its own interval unknown (e.g. all other actions proven losing). Unlike K42, root value need not exact and tie need not equal exact ascending minimax. Deterministic smallest-index certified action. If not certified and MCTS chooses a with u_a=-1, any legal b has v_b>=-1=v_a; replacing with highest-vote not-proven-losing action is weakly nonworsening in true minimax regret. No strict improvement or path parity claim after replacement; unknown alternatives may all lose. If no alternative, do not replace. Retain same-horizon L/B recommendation parity before proof replacement. Exact action proof = zero simple regret; finite vote lock = same recommendation, different guarantee.
Cost/occupancy: for a sampled unresolved frame, q=Pr(certificate), m=Pr(replacement), C_proof measured CPU incl unsuccessful attempts. Same-root net NN saving from cert is E[1_cert C_B]+E[1_no_cert(C_B-C_L)], no inference to full-game trajectories. CPU net uses same root actual CPU: C_B-(C_proof+1_no_cert C_L), with common gate cost counted once as executed; masking may change future trajectory. Compare depth3/5/7 and fixed costs; no assumed monotone coverage across independent budget-limited traversals. Retain actual count distribution, no posthoc choice of depth. Proof computation has exact value guarantee, statistical MCTS and utility estimation separate; empirical cost trade-off not universal optimal resource policy.
