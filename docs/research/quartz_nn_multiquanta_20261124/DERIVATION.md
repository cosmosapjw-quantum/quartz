# Cost discretization and uncertainty: derived
Let option j=0 denote STOP. For every root i and option j, true expected signed gain g_ij, deterministic nonnegative realization cost c_ij, fitted gain h_ij and fitted cost d_ij. Assume uniform gain error |g-h|<=epsilon and cost error |c-d|<=delta for nonzero options (0 exactly). Let q=ceil((d+delta)/Delta) for nonzero j and q_i0=0. Budget K=floor(B/Delta). Then q*Delta>=c, so any discrete feasible plan is true feasible under these deterministic bounds. Conversely q*Delta<c+2delta+Delta for each selected option, so any plan with true cost <= B - n(2delta+Delta)-Delta is feasible (one extra Delta conservative for the floor). This implies
G_B^true - G_true(plan_DP) <= [G_B^true - G_{B-slack}^true]+2n epsilon,
where G_true(plan_DP) here denotes TRUE utility of the plan optimizing fitted gains on the quantized conservative feasible set; proof via adding/subtracting fitted gains twice and discrete optimality against a true optimum at tightened budget. Refine n to max selected nonzero options if known. Nonnegative STOP makes optimum nondecreasing in budget; slack can remove high value near a threshold, so no universal small utility penalty as Delta decreases unless delta shrinks and frontier is locally regular. This is not a stochastic wall-time guarantee: a calibration mean/median or marginal quantile does not give simultaneous deterministic cost bound. Union bound P(any c>d_i+margin_i)<=sum_i p_i for a fixed plan with valid conditional tail bounds; adaptive selected plans require conditional bounds under their selection, not marginal coverage.
Recurrence V_0(b)=0, V_i(b)=max_{j:q_ij<=b}(V_{i-1}(b-q_ij)+h_ij), backpointers O(n K J) time/O(nK) reconstruction. Induction: the last root consumes q and leaves a feasible first i-1 solution; every candidate corresponds to a feasible concatenation. Non-adaptive plan only. A resource-price upper bound for any lambda>=0 is lambda K+sum_i max_j(h_ij-lambda q_ij), by rearranging the budget inequality. Ratio is not optimal: B=4, roots with positive options (3,5),(2,3),(2,3) and stop. Greedy ratio chooses first, DP chooses last two; regret 1.
Physical decomposition T=setup+prefix+optional search+plan+drop+other, with other including host scheduling and response serialization/IPC. A point cost estimate is a forecast, not the realized T. Distinguish predicted objective from observed WDL and physical timing. Do not use empirical timing equality to prove mathematical guarantee.
