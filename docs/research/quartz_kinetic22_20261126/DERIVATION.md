# Causal response-channel decision theory
Notation: finite legal actions A, U in [0,1]^A fixed latent utilities, common information H, P=P(U|H). Intervention c selects a computation protocol (fixed prestate, evaluator, seed policy, resource rule and readout), yielding response Z_c, cost K_c and decision d_c measurable in (H,Z_c). Kernel L_c(z|u,H) is conditional statistical model across root/seed worlds, not literal stochastic physics. Randomized logging p(c|H)>0 independent of potential responses conditional on H; in isolated simulator we can run every fork (same deterministic prefix, no shared mutable tree; reset evaluator counters). Across roots runtime interference/timing can remain; WDL/NN deterministic checks separate. SUTVA concerns root+protocol versions, not root edges, which interfere by design. No post-treatment conditioning for primary effect. Wager ch1,2,5,6,14 and Polyanskiy–Wu ch2,3,28.
## R4 competing quantities
For a common panel P_A subset A chosen at H, m_a=E U_a, M=max m_a. Model joint law P(U,z|H,do c)=P(U|H)L_c(z|U,H), with shared P across c. Marginal z probability p_c(z); posterior m_c(z). Hard Bayes gain G_c=E max m_c-M >=0. Latent information I_c=E_z KL(P(U|z)||P(U)), in nats. Gibbs gain G_tau,c=E Phi_tau(m_c)-Phi_tau(m)=tau E KL(q_pre||q_post) (K21, PW Prop4.7). Actual signed native gain D_c=E[U_d_c-U_d0] can be negative; objective D_c-lambda E K_c. Native d_c can be outside panel, so panel model is separate counterfactual approximation, not prediction identity. Compare direct signed gain learner and MI/EVSI-ranked channel policies; both predict with prestate only. FOCUS (force runner-up first 4 visits) and RESERVOIR (force highest-prior outside prefix pair first 4 visits) followed by ordinary continuation; full candidate set already exists, no actual tree widening claim. STOP remains prefix baseline, not eligible in fixed NN allocation comparison.
## R5 constructive results
1. For bounded utility range [0,1], M(P)=max_a E_P U_a is 1-Lipschitz in TV(P,Q)=1/2||P-Q||_1: each action expectation differs by at most TV, then use a maximizing action on either side. Thus 0<=G_c<=E TV(P_z,P)<=sqrt(I_c/2), natural logs; Pinsker PW Eq7.27, Jensen. Tuisov 2026 Theorem2 already states loss version. K21 EVPI and centered-contrast moment bound also hold, so take min of all three. Not valid for raw scores or misspecified posterior as true-world certificate.
2. For S=f(Z) or U->Z->S at fixed H,c, tower gives m_S=E[m_Z|S]. Loss of decision value
L_S=E max m_Z - E max m_S >=0.
Apply same Lipschitz argument conditionally on S to P(U|Z,S) and P(U|S), obtaining L_S<=E TV<=sqrt(I(U;Z|S,H,do c)/2). Exact chain I(U;Z)=I(U;S)+I(U;Z|S) under the stated Markov relation. If CMI=0, no Bayes decision loss; converse false (same maximizer can remain, unrelated common-mode information). Blackwell garbling implies no improvement for any bounded utility, whereas MI order alone does not. Equality in Jensen max occurs iff some S-measurable maximizer is also a Z-maximizer almost surely, finite actions (nonnegative gap with expectation zero). K21 CMI complements drift/KL: these are different measures. For deterministic duplicate Z2=Z1 conditional MI=0; genuinely independent conditional likelihood is not assured by identity differences. XOR example U=(1{B1 xor B2=0},1{B1 xor B2=1}), independent fair bits: each query G=0, together G=.5; two-step gain and no general submodular VOC.
3. Actual readout loss identity on same full A and coherent channel: let e0=M-E[U_d0|H]>=0, ec(z)=max m_c(z)-m_c(z)_{d_c(z)}>=0. Then D_c=G_c+e0-E ec. Therefore good information with poor decision can hurt, and native gains may exceed G_c if initial readout suboptimal. If panel excludes native action, identity cannot be used for native D. Exact decomposition with full A only. No assumption that native mean is calibrated.
4. Finite population: units i fixed root/seed, rewards Y_i(c)=U_i(d_i(c))-lambda K_i(c) (incremental NN count, dimensionless utility/NN, lambda=.002); possibly also signed relative prefix or N. Define V(pi)=n^-1 sum_i sum_c pi_c(X_i)Y_i(c). Each unit's first executed randomized logged arm C_i~e_i(.|X_i), independent random seeds and no oracle. AIPW for frozen policy pi and fixed external nuisance mu_i(c):
psi_i(pi)=sum_c pi_c mu_i(c)+pi_C/e_C (Y_i(C)-mu_i(C)).
E_C psi_i= sum_c pi_c Y_i(c) exactly by finite sum. For contrast pi-rho replace pi by pi-rho, so equal-action units contribute exactly zero. Bias under wrong ehat is sum_c pi_c(1-e_c/ehat_c)(mu_i(c)-Y_i(c)). If e correct, exact unbiased for arbitrary fixed nuisance; if mu correct (conditional expectation), unbiased in expectation over outcomes, not necessarily fixed finite potential outcome. Conditional assignment variance v_i=sum_c e_c [pi_c/e_c*(Y_i(c)-mu_i(c))]^2 - [sum_c pi_c*(Y_i(c)-mu_i(c))]^2. For contrast same formula with weights pi-rho. Fixed independent assignments Var(mean)=sum_i v_i/n². Because full paired outcomes measurable in simulator, exact finite-population contrast is stronger than sparse OPE; use full atlas to benchmark sparse IPS/DR, not to claim asymptotic normality. If replay/order changes outcomes or common mutable tree contaminates forks, fixed potential outcome model fails; verify live repeats where possible. Measured wall time contextual; not causal timing exact because of host interference.

Dynamic extension Wager Assumption14.1, Eq14.6,14.21 and PW Thm2.16/3.7: with histories H_t, independent exploration, consistency, common transition K_t and overlap, P_pi=P_0 prod pi_t K_t, importance ratio W_t=prod pi/e. For per-step cost reward r_t and terminal utility V_T, DR telescopes E[Vhat_0+sum W_t(r_t+Vhat_{t+1}-Qhat_t(H_t,C_t))]=V_pi if Vhat_t=sum pi Qhat_t and terminal convention fixed. ## R6 limits
Fixed support and positive priors; zero mass treated exactly; impossible response ignored. Utility normalized WDL, all-information bound nats; bits require ln2. Costs additive, distinct from energy. KL orientation latent post||pre vs Gibbs pre||post. No policy-independent kernel assumption on compressed H unless checked. Causal intervention is not conditioning on observed chosen action without overlap. Finite sample no CLT by default. AIPW does not fix a misspecified scientific estimand or lack of support. Common-mode and XOR counterexamples protect old W1 and C28. Rate-distortion PW Thm24.3 suggests decision distortion D=E[max U-U_d] and log M>=inf I(U;d) under valid bottleneck and distortion constraint; zero distortion may allow multiple optimal actions; no iid coding theorem transfer.
