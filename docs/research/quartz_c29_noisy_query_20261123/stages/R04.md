# R04: noisy terminal decision, normalized and unnormalized H2 Bellman equations

Let h record actual queries and observations. Let W_h(omega) >=0 be unnormalized mass over complete fixed utility worlds omega in Omega, and Z_h=sum_omega W_h(omega)>0. For a query i with observation y, branch mass W_{h,iy}(omega)=W_h(omega)*C_i(y|U_i(omega)); its total is Z_{h,iy}. Channel normalization gives sum_y Z_{h,iy}=Z_h. Repeating i is permitted; each observation likelihood multiplies the SAME world's mass.

Terminal action value under posterior-mean deployment:
T(W)= max{ b*Z, max_i sum_omega W(omega) U_i(omega) } / Z.
Normalized finite-horizon recursion: V_0(W)=T(W),
V_k(W)=max{T(W), max_i[-c_i + sum_{y:Z_y>0} (Z_y/Z) V_{k-1}(W_y)]}, k=1,2.
An optimal policy can STOP at any depth. All c_i >=0 are utility per query and can vary by candidate.

Define G_k(W)=Z V_k(W) for Z>=0, with G_k(0)=0. Then an exact division-free Bellman recursion is:
G_0(W)=max{b Z, max_i sum_omega W(omega) U_i(omega)},
G_k(W)=max{G_0(W), max_i[-c_i Z + sum_y G_{k-1}(W * C_i(y|U_i))]}.
Proof: multiply the normalized Bellman by Z>0; the factors Z_y/Z cancel even for a zero-likelihood y because G(0)=0; induction establishes the equality for k=1,2. Multiplication and max preserve positive homogeneity G_k(tW)=t G_k(W) for t>=0. No division is needed inside H2 branching; division by Z is only required to display normalized values.

Under known-only exact-reveal compatibility, T(W,K)=b(K)*Z, and observing exact u adds i to known set K and updates b(K); unknown candidates may not be deployed. This is a DISTINCT terminal contract and its state includes K. For an identity channel C(y|u)=1[y=u], with no repeated already-known queries, the recursion reduces to C28's direct Bayes H2 (not C28's specific lifted signed formula unless its initial signed prior is also imposed).

For any conditional-independent channel, an uninformative query C_i(y|u)=c_i(y) leaves the posterior W/Z unchanged. With strictly positive cost and no other state effects, it cannot strictly improve optimal future value: skipping it preserves the belief, leaves at least as many queries, and saves cost. If every available channel is uninformative, V_k=T for all k. A noisy query should not be marked exact-known merely because its observation is extreme; only an actual exact value or a posterior point mass proves utility.

Numerical risk: normalized factor updates divide by small a_z/D; unnormalized world recursion can underflow for very long histories. C29 H2 small-support exact Fraction oracle avoids these concerns, and native f64 inputs use bounded histories, finite/normalization validation, and zero-mass branch exclusion. No general floating-point error theorem is inferred from finite tests.
