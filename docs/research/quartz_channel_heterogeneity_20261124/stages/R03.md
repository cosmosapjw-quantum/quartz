# R03

Let U in {0,1/2,1}, R in simplex of rollout outcome probabilities, X=remaining depth. For fixed actual board, fresh independent uniform rollout draws are iid given R, not necessarily given only U. Finite TRAIN mixture atoms (u_k,r_k,w_k>0), sum w=1. Histogram n=(n0,n1,n2) includes the four cue observations. M(n)=sum_k w_k prod_y r_ky^n_y, A(n)=sum_k w_k u_k prod_y r_ky^n_y. Posterior E U=A/M; predictive p(y|n)=M(n+e_y)/M(n). Histogram is sufficient for this iid conditional mixture; not for arbitrary stateful MCTS. Smooth each r by (31/32)r+(1/32)/3 and add one uniform component per utility/depth to guarantee support. Units U dimensionless, cost lambda_nodes=1/1024 utility per visited state. P(U|cue) common to all arms in comparison; oracle only TRAIN/offline.
