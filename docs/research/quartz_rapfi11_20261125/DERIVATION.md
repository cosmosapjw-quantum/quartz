# Exact finite recommendation reachability
Let A ordered by immutable candidate rank i=0..m-1, n_i>=0, sum n_i=N>0, hidden counts zero. Native recommendation is max lexicographic (n_i,i) over materialized prefix (last equal max). Because N>0, adding hidden zeros cannot change leader L. Given remaining b visits and arbitrary nonnegative integer increments x_i summing <=b, define d_j=n_L-n_j+1_{j<L} for j!=L. These are positive. If j outranks L on ties then d_j=n_L-n_j; otherwise strict greater count required. For j to overtake L, x_j-x_L>=d_j, hence x_j>=d_j. Necessity holds irrespective of selection policy and widening; sufficient in relaxed allocation model by assigning d_j visits to j and none to others. It also makes j overall leader because every other action has initial score <=L and j beats L; extra remaining visits can go to j. Actual native PW/PUCT may not make j reachable, so d_j is necessary, not sufficient for actual search. Hidden action considered even if not currently materialized. Exact certificate min_j d_j>b implies unchanged final visit-argmax for any feasible remaining trajectory. For a singleton min is infinity. This certifies finite-budget recommendation identity, not game utility or optimality. The converse means only relaxed possible flip.
