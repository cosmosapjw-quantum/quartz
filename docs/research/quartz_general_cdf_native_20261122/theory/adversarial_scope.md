# R06 | Falsifiers and scientific limits

Wrong independence: if θ_1=θ_2 almost surely, the marginal Beta posteriors may be identical but X_1 and X_2 are correlated; product of marginal CDFs is false. Posterior cross-arm dependence from common shocks or adaptive tree backups requires a joint model or upper/lower bounds. Source Beta generator uses *independent* arms, not real neural-MCTS. Repeated samples *within* each arm depend unconditionally through same θ, which Beta-binomial correctly models. A source with missing terminal action cannot support global decision regret, only actions supplied.

Numerical degeneracy: same posterior mean from supports of different arms and repeated rational representations; double total order may split mathematically equal scores if evaluated under different arithmetic paths. Audit both integer rational tie oracle and float residual vs full grid. For very small shape parameters and huge n, p0 may underflow; this C21 algorithm explicitly bounds parameters and n, does not silently emit plausible but unnormalized values. Even a fast correct CPU function can be operationally expensive via language boundary/JSON or run-to-run wall time variance; report internal vs streaming vs cold-spawn separately.

Data leakage: true latent θ/μ, extra sample draws, final action and actual *future* task cost must not enter precomputation model. Training price bucket depends on declared task kind and initial action count, which can encode source class, so a shared overall controller is not proven domain-transfer. For C21 raw outcomes, require new unique sources rather than previously seen C20 TEST. No claim of original P2 resource saving without active actuator, P3 human signature, P4 production gates or actual MCTS signed utility. Negative cost outcomes are a valid physics-of-computation result, not a reason to inflate methodology gates.
