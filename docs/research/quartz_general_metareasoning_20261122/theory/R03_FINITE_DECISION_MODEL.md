# R3. Explicit general Bayesian computation-selection model

Define finite latent world Θ={θ1..θS}, feasible terminal actions A={a1..aK}, posterior b∈Δ_S, utility U(a,θ) real and finite. Decision utility is measured in one common utility unit; negative payoffs are allowed. For an experiment/computation c, observation alphabet Y_c finite, conditional channel L_c(y|θ) normalized over y for every θ, and deterministic resource cost k_c>0. The agent observes y drawn from p(y|b,c)=∑_θ bθ L_c(y|θ), updates b'_θ=bθ L_c(y|θ)/p(y|b,c) when p>0. Computational action may be repeated, conditionally independent given θ in the bounded reference model. A model with dependence on previous computation outcomes would require an expanded latent state and must NOT be silently treated as conditionally IID.

Perfect-information benchmark K(b)=∑_θ bθ max_a U(a,θ); no-additional-computation Bayes action value M(b)=max_a∑_θ bθ U(a,θ). Define posterior simple decision regret R(b)=K(b)-M(b)≥0. This is the *risk of the best terminal Bayes action* under the specified model, not the realized regret of an arbitrary single rollout. It differs from root ranking regret when the optimal action is not in the evaluated candidate set. Full action set and observation channel are an explicit input.

One-step gross value G_c(b)=R(b)-E_y R(b'_y). Equivalent (calibrated model) G_c=E_y M(b'_y)-M(b); future oracle K cancels by tower property. Net (priced) gain with exchange λ>0 utility/resource is N_c(b)=G_c(b)-λ k_c. Rate I_c=G_c(b)/k_c. Under one compulsory computation with no option to stop, choose max G if costs constrained equal, choose max N if priced and variable costs, choose max I only as a *separately specified index heuristic*.

At most H more computation actions: V_0(b)=R(b), and V_h(b)=min{R(b),min_c[λk_c+∑_y p(y|b,c)V_{h-1}(b'_y)]}. Choosing STOP is a real meta-action. This recurrence is over a finite branching problem with costs charged at each observation and terminal action executed only after stopping; it is not a self-referential proof of online MCTS efficacy.

Conventions: λ includes conversion of milliseconds/NN evals to terminal utility and must be explicitly calibrated or swept. A raw ratio G/k has units of utility/resource, not a pure dimensionless score. For k>0 the one-step stop predicate "all I≤λ" is equivalent to "all N≤0"; it does NOT make the optimal non-stop computation rankings equivalent. An observation that never changes the optimal terminal choice has G=0 even if posterior entropy falls.
