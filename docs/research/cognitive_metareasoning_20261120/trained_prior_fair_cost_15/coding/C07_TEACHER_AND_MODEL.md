# C7. Actual 160 pretrained Rapfi finite-budget teacher labels, frozen trained model

Source experiment protocol code was published at C07A Git 54965ec95c94d4763d7afa12ef5d9515c3906169 before any teacher evaluation. Real external Rapfi engine rule0 Freestyle15 with verified original 2025-06-15 executable/model SHA queried 160 newly frozen position histories (128 train+32 validation), each 300ms requested finite search. Actual total teacher elapsed 40.77 sec, mean response elapsed 241.43ms (wall clock includes native engine process). Recorded all 160 legal engine moves and original source group IDs; no test labels were acquired. Label file SHA256 d4e66ba0f9af0006e1efff9af9ce5224b56ea6e9d7c00fba7a97e0078ba2eb71.

Trained C05 13-feature policy-only log-linear model with L2 lambda .01 and deterministic damped full-batch Newton. Objective gradient inf norm 5.3653e-12 after 7 iterations (strictly convex with positive L2). Model SHA256 **5ff8286dcc57192b79e960ba096bc5067c78d439a212eaa69d523f68835a3b83**; exact features/weights in evidence/model/MODEL_TRAINED.json and SHA receipt evidence/model/MODEL_C07_FREEZE.json.

Finite-source surrogate metrics: train top1 teacher-action agreement 49/128=38.28125%, top16 coverage 123/128=96.09375%, log-loss 2.33237; validation top1 11/32=34.375%, top16 29/32=90.625%, log-loss 2.59577. Validation splits are independent D4 board canonical groups; however these are seeded synthetic states, not expert-game populations. This measured surrogate is **not an independently pretrained full Gomoku15 policy/value ONNX network**, and matching a teacher's finite recommended action is NOT equivalent to game win-rate or minimax accuracy. No model inference was previously present in C14 uniform evaluator; trained policy is a real improvement in representation, not a proven game-strength improvement.
