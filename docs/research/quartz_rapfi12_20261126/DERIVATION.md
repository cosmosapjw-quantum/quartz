# Resource-constrained metareasoning and calibration
For fixed state distribution rho, conditional action utility G(s,b)=E[U(s,a_b)], C(s,b)=E[cost|s,b]. With finite budget menu and stochastic mixtures, the problem max E_rho G subject to E_rho C<=T has the Lagrange upper bound inf_lambda>=0 {lambda T+E_rho max_b[G(s,b)-lambda C(s,b)]}. For any feasible policy each pointwise max bounds its value, so weak duality follows. For finite rho and finite menu with feasible linear constraints, LP strong duality; no claim for endogenous game-state distribution or unobserved G. If two budgets are mixed with probability q, expected C=(1-q)C_l+q C_h; when C_l<=T<=C_h and unequal choose q=(T-C_l)/(C_h-C_l). This matches expectation on calibration rho, not realized wall or another distribution. Never extrapolate if no bracket: nearest measured endpoint and flag mismatch. No outcome-based budget tuning.
