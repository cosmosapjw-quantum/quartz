## 4. 계산비용 일치 실험 C8

동결된 48+16개 시험 국면에서 실제 Rust CPU MCTS를 3개 arm으로 **192회** 실행했고, 원자료를 먼저 공개했다. 그 후 별도로 실제 Rapfi 시험 라벨 64개를 획득했다. 목표 20,000µs(모델 파일 로드와 JSON 직렬화 제외; 실제 정책 평가·루트 생성·one-ply 규칙·MCTS 포함)에서 학습된 prior 두 arm의 평균 시간 불일치는 자연 합성 **0.01577%**, 구성 전술 **0.01685%**였다. 사전 지정한 각 층 10% 이내 기준을 모두 통과했다.

| 동결된 평가군 | 학습 prior + 재개방 | 학습 prior + 전체 합법 수 | Uniform + 전체 합법 수 |
| --- | ---: | ---: | ---: |
| 합성 자연 48개, Rapfi 단일 착수 일치 | **22/48** | **22/48** | 2/48 |
| 구성 전술 16개, 합법적인 즉시 승리 수 선택 | **16/16** | **16/16** | 13/16 |

자연형 합성 국면에서는 동일 비용에서 학습된 prior의 Rapfi 한 수 일치가 Uniform보다 높았다. 이는 **고정 합성 표본의 유한시간 교사 모방 결과**이며, 대국 승률이나 실제 minimax에 관한 주장은 아니다. 원래 학습된 전체 탐색은 Uniform보다 같은 시간에 더 적은 루트 방문을 수행했으며, 모델 평가비용과 방향성의 교환관계를 함께 보아야 한다.

**핵심 음성 결과:** 재개방 트리거는 **0/64**, 실제 추가 후보는 **0개**, 학습 prior 재개방군과 학습 prior 전체 탐색군의 최종 수는 **64/64 동일**했다. 따라서 현재 시험으로는 *학습된 prior에서 후보 재개방 자체의 독립적인 이득이 전혀 확인되지 않았다.* 트리거가 발동하지 않았으므로, 발동 조건에서의 인과효과는 추정할 수도 없다.

또한 전술 16개 중 14개는 둘 이상의 즉시 승리 수를 지녔다. 학습 prior 전체 탐색이 16/16 승리 수를 두었어도 Rapfi와 정확히 같은 착수는 7/16이었다. Uniform은 정확 일치 13/16이지만 실제 승리 수는 13/16이었다. **교사 한 수의 정확 일치와 규칙상 승리 동등성은 반드시 분리해야 한다.**
